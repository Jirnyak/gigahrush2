568|    // MemNone). Three-stage placement, all of it a fixed 8-slot scan:
569|    //   1. COALESCE an existing live trace with the same (kind, payload) —
570|    //      refresh `seenAt`, keep the STRONGER strength. This is what stops a body
571|    //      standing in a hot cell for 200 ticks from filling all 8 slots with the
572|    //      same fact, and it is the reference's `existing.severity = max(...)`,

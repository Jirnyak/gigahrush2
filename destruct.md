# Destruction — the universal carve

> Code: `src/world/destruct.h/.cpp`, `src/world/subfield.h`,
> `src/world/material_props.h` · Tests: `tests/suite_destruct.inl` ·
> Related: [voxels.md](voxels.md), [fields.md](fields.md), [nav.md](nav.md),
> [props.md](props.md), [antourage.md](antourage.md)

Мир состоит из клеточек (128³ macro cells) и субклеточек (8³ битов в каждой).
Разрушение — это ЕДИНСТВЕННЫЙ универсальный способ, которым геометрия теряет
субвоксели. Кирка, пуля, взрывчатка, самосбор, монстр, грызущий стену — всё
это один и тот же **carve**: «приложи `power` в такой-то форме с таким-то
seed». Система смотрит материал каждого затронутого субвокселя и бросает
кость; она не знает, КТО ударил. Контекст (форма, сила, что делать с обломками)
остаётся у инструмента; физика сопротивления — здесь.

## Вероятностная прочность (stateless, детерминированная)

У каждого материала — строка `kMatHardness[]` ([material_props.h]). Шанс
удаления субвокселя = `min(1, power / hardness)`, решается ЦЕЛОЧИСЛЕННО против
хеша `carve_hash(seed, cell, bit)`:

```
удалён  ⇔  (hash & 0xFFFF) * hardness  <  power << 16
```

* `power == hardness` — гарантированный снос; половинная сила — монетка.
* Ни RNG-потока, ни хранимого HP: «долбление» киркой — это серия ударов,
  каждый с новым seed (= новым тиком), новый бросок.
* **Сервер — источник истины** ([netcode.md]): он выбирает seed, и тот же op
  с тем же seed воспроизводится бит-в-бит на любой машине. Реплей и поздний
  join проигрывают лог carve-команд, а не гоняют маски по сети.
* Сентинели: `hardness 0` — снимается любым касанием (пыль);
  `kHardnessUnbreakable` — не carve-ится никогда. Так инфраструктура защищена
  ДАННЫМИ, а не if-ами: двери (их ломает их собственный автомат [door.h]),
  hub-пады и extract-пады — unbreakable-строки таблицы.

## Слоёные материалы: «краска снаружи, бетон внутри»

Материал ячейки — по-прежнему один `CellType`, пока кто-то не нарисует слои.
Тогда включается **`SubField<CellType> "sub_material"`** ([subfield.h]) — и у
каждого субвокселя свой id. Генератор красит `set_sub_material()`; взрыв
срывает краску (hardness 32) везде, оспинами бьёт бетон (256) и обнажает то,
что сломать не смог. Уникальная ячейка не платит НИЧЕГО; закрашенная — одну
страницу 8³.

`SubField<T>` — универсальная paged-sparse система субвоксельных полей
(материалы сегодня; заряд, температура, что угодно — завтра), реестр
`world.subfields()` зеркалит `world.fields()`. Контракт деградации: три
плоских вектора (page-таблица 8 МБ + страницы + free-list), чтение — две
индексации, и в ХУДШЕМ случае (все 2²¹ ячеек смешаны) поле `uint16`
вырождается ровно в dense-массив: **2 ГиБ страниц + 8 МБ таблицы**, линейно по
числу смешанных ячеек по дороге. Типичный этаж — десятки МБ.

## Отрыв от опоры (handoff-шов с рендером)

После удаления каждый 6-связный компонент ≤ `detachLimit` субвокселей, не
держащийся ни за что большее, **удаляется из грида** и возвращается в
`CarveResult::detached` (позиция + материал). Это и есть шов: контракт
симуляции заканчивается на «эти воксели больше не мир» — рендер симулирует их
падение/разлёт как хочет (сейчас — `emit_destruction_burst`, материальные
частицы; поток данных строго Sim → Render, [render.md]).

На торе нет «земли», поэтому «держится» определено операционально: bounded
flood-fill (плоская open-addressing таблица в переиспользуемом
`CarveScratch`, ноль аллокаций после прогрева) перелился через лимит ⇒
опора есть. Большие подрытые массивы стоят — их судьба принадлежит
sandpile-правилам ([sim/cellular.h]), не carve-у.

## Перепекание — ОТДЕЛЬНЫЕ шаги (by design)

Carve НЕ перепекает ничего. Коллизия жива сразу (физика читает маски). Долг
вызывающего — ровно `CarveResult::dirtyCells`:

| Потребитель | Что делать | Стоимость |
|---|---|---|
| Рендер | `voxelMirror.mark_dirty(dirtyCells)` | 64 Б/ячейка PCIe-аплоада, без rebuild |
| Diffusion / Cellular | `*_mark_cell()` на каждую dirty-ячейку | O(1) патчи |
| Nav (flow fields) | **ничего** — stale до следующего полного bake | тот же принятый долг, что у дверей |
| Пропы ([props.md]) | `anchor_validate_step()` | мебель без опоры отрывается по своему `PropFallMode` |
| Антураж ([antourage.md]) | `antourage_carve_step()` | перерубленные трубы/провода/шторы сыплют обломки и перестают рисоваться |

Последние две строки — один и тот же вход (`dirtyCells`) и один и тот же
возврат: «сколько отвалилось». Ненулевой = перепаковать статичную шкуру
`PropPass`, иначе GPU продолжает рисовать мебель и трубы, которых уже нет.
Проб на «живость» не кэшируется нигде: carve умеет только превращать твёрдое в
воздух, поэтому грязный список операции называет РОВНО её жертв.

## Приложение

Консольная строка `carve [radius] [power]` (ряд в таблице команд) —
предлагает; sim-цикл исполняет на своём такте, **никогда во время nav-bake**
(тот же freeze, что у дверей; запрос ждёт, не теряется). Звук — noise_publish,
дебрис — частицы по материалам, seed — номер тика.

## Рендер: честный субвоксель

Атом мира — субвоксель 0.25 м, и рендер рисует его честно — теперь
буквально: реймарчер ([render.md]) трассирует те САМЫЕ биты масок через
GPU-зеркало ([render/voxel_mirror.h]), материал каждого субвокселя берётся
из страниц `sub_material` (страница ? страница[бит] : CellType — тот же
контракт `sub_material_at`). Мешера больше нет: кратер от `carve` виден в
следующем кадре ценой 64 Б/грязная-ячейка аплоада, AO считается
per-pixel на субвоксельном уровне (старая граница «плоская светотень
кратеров» закрыта), а шахматка падика стоит DDA столько же, сколько
сплошная стена.

## Сейв: модульный, как сама игра

Папка `gigahrush2_save/` ([save.h] v5, [jirnyak.md] §6 — диск бесплатен на
лоад-скринах, а переход этажа и есть лоад-скрин):

* **`run.sav`** — ран И макромир ([save.h] v6): леджер, контракты, игрок,
  ящики, квесты, ПЛЮС вся таблица NpcPool verbatim-колонками
  (`save_rows`/`load_rows` — общество, к которому возвращаешься, то самое,
  а не пересев), часы/курсоры/journeys макро-сима и живая фракционная
  матрица. ~612 КБ на живой популяции 1940 строк. Геометрии здесь нет
  никогда. Слоты: `slot1..slot8`, выбираются в **главном меню** (отдельный
  экран: New Game / Load Game / Settings / Quit, расширяем рядами — экран
  создания персонажа сядет сюда же страницей, т.к. игрок = строка пула).
* **`floor_<N>.sav`** — точный грид каждого посещённого этажа (types RLE +
  маски empty/full/mixed-RLE + sub_material-страницы; ~5 МБ на этаж против
  138 МБ сырых массивов). Пишется, когда игрок **уезжает** с этажа (и для
  резидентного — при каждом сейве); штампуется поверх генерации при **каждом**
  построении этажа, до `door_build` и nav-bake. Ревизит на лифте и F9 — один
  и тот же код. Нет файла — этаж генерится девственным.
* **Автосейв** на каждом переходе (`save_run_now`: run.sav + файл резидентного
  этажа); при старте, если ран на диске есть, игра продолжается сама
  (начать заново = удалить папку). Крах стоит максимум прогресса текущего
  этажа.
* Загрузка трогает ровно два файла — run.sav и файл активного этажа;
  остальные этажи подгрузятся из своих файлов, когда игрок туда пойдёт.

Слепок — состояние, а не история: same-floor F9 **раз-капывает** дыры,
сделанные после сейва. Тест: `floor_file_round_trips` (carve → запись файла →
carve ещё раз → штамп на свежего близнеца → бит-в-бит момент записи, слои
краски включительно; пять ворот отказа — magic/version/size/CRC/обрубок).
Живой прогон: carve на этаже 0 → лифт → выход → загрузка вернула на −8 из
его файла, ноль отказов.

## Известные границы (честно)
* `sub_material` страницы удалённых субвокселей хранят последнее значение —
  оно замаскировано битом occupancy и не читается.

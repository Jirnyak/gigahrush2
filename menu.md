# Меню — стартовый экран, пауза, настройки

Каркас уже существует и работает ([src/app/main.cpp] `menuScreenPage`,
`menu_start_playing`): страницы Main → Load / New Game / Settings, слоты
1..8 как ДИРЕКТОРИИ (`gigahrush2_save/slot<N>/`, [save.h] — меню выбирает
слот, не файл), New Game честно чистит слот целиком. Этот документ фиксирует,
куда каркас растёт, чтобы добавки были строками, а не переписыванием.

- **Код:** [src/app/main.cpp] (страницы меню, `slot_occupied`,
  `slot_dir_path`), стиль — [src/render/imgui_layer.cpp] (CRT-мандат)
- **Статус:** стартовый экран и слоты — построены; пауза и настройки
  интерфейса — дизайн.

## Состояния приложения

`Menu → Game ⇄ Pause`, и это ЯВНЫЙ маленький автомат, не набор булей:

- **Menu** — стартовый экран; симуляция не создана или заморожена, ввод у меню.
- **Game** — симуляция тикает, ввод у тела, худ рисуется ([hud.md]).
- **Pause** — Esc из игры: сим-аккумулятор стоит (кадры идут — CRT живёт,
  мир замер), поверх — то же меню со страницами Resume / Settings / Save /
  Quit-to-Menu. Пауза — свойство ОДИНОЧНОЙ игры; при живом сервере
  ([netcode.md]) пауза локального клиента мир не останавливает.

Инвентарная сетка ([inventory.md]) и консоль — НЕ состояния этого автомата:
они оверлеи поверх Game (сим продолжает тикать).

## Страницы

| страница  | что на ней | статус |
|-----------|------------|--------|
| Main      | Continue (последний слот) / New Game / Load / Settings / Quit | есть (без Continue) |
| New Game  | слоты 1..8 с пометкой overwrite; выбор чистит директорию слота | есть |
| Load      | занятые слоты; загрузка на сим-клоке следующего кадра | есть |
| Settings  | вкладки: Interface / Controls / Video / Audio | зачаток |

### Settings → Interface

Тумблеры элементов худа — по строке на элемент таблицы из [hud.md]. Состояние —
настройки ПРИЛОЖЕНИЯ (файл рядом с биндами, [main.cpp] `save_binds` уже задаёт
паттерн), не сейв рана: интерфейс принадлежит человеку, персонаж его не носит.

### Settings → Controls

Бинды уже сохраняются (`save_binds`/`bind_key`); страница делает их видимыми
и перебиндируемыми. Конфликт биндов — красная строка, не тихая перезапись.

### Settings → Video / Audio

Video: разрешение/фуллскрин/vsync — то, что уже умеет рендерер, без обещаний.
Audio: заглушка до появления звука; пустая вкладка честнее фальшивой.

## Стиль

Тот же CRT-мандат, что и худ ([imgui_layer.cpp:36-60]): фосфор на почти-чёрном,
нулевое скругление, толстые рамки. Меню — та же служебная аппаратура, что и
стекло худа; стартовый экран не «красивее» игры, он ИЗ игры.

## Чего меню НЕ делает

- Не держит игровых данных: слоты — директории на диске, настройки — файл
  приложения; меню лишь показывает и вызывает существующие пути.
- Не встраивает консоль: консоль — отладочный инструмент с собственным вводом.
- Не автосейвит по своим правилам: сейв-закон один ([save.h] — F5 и конец
  поездки), страница Save зовёт его же.

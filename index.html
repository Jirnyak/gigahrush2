C++23 • Vulkan • Zero-Allocation

The Universal
Voxel Core Engine

The substrate you build a voxel game on. Dense data model, vector gravity, swept-AABB physics, and an instanced cube Vulkan renderer. Built for 128³ macro worlds.

View Source Read Documentation
⚡

Vulkan Rendering

Instanced cubes with surface culling keep instance counts proportional to visible area, rendering vast 128³ worlds efficiently via MoltenVK & SDL3.

🧊

Sub-Voxel Precision

Every macro cell holds an 8³ sub-voxel blocker mask. Swept-AABB physics allows collision to be fine-grained and incredibly cheap to query.

🌊

Vector Gravity & Fluids

Gravity is a 3D acceleration vector, not a static "down". Features deterministic mass-conserving cellular fluids as runtime typed fields.

🚀

Modern C++23 Core

High-concurrency chunk generation with coroutines, zero locks, and an EnTT-backed Universal ECS for decoupled entities and logic.

# Requires CMake ≥ 3.20, C++23 compiler brew install sdl3 vulkan-headers vulkan-loader molten-vk shaderc cmake -S . -B build -DCMAKE_BUILD_TYPE=Release cmake --build build -j # Run the demo engine ./build/gigahrush2

## 📖 About

**GIGAH|RUSH 2** brings the infinite brutalist nightmare of the *Khrushchyovka* into full 3D. Built on **Unity**, the sequel expands the Samosbor universe with volumetric atmospheric red emergency lighting, interactive blast door physics, air contamination systems, and deep procedural floor architecture.

You're not just surviving anymore — you're unravelling the mystery of *why* the Samosbor started.

---

## ✨ What's New in GIGAH|RUSH 2

| Feature | Description |
|---|---|
| 🌑 **Full 3D Engine (Unity)** | Volumetric lighting, real-time shadows, atmospheric fog |
| 🚪 **Blast Door Physics** | Interactive germ-proof doors with physical locking mechanisms |
| ☣️ **Air Contamination System** | Real-time radiation and atmospheric toxicity simulation |
| 🏗️ **Deep Procedural Architecture** | Multi-section, multi-floor procedural concrete block generation |
| 🔊 **Spatial Audio Engine** | 3D positional audio — hear Samosbor before you see it |
| 🛠️ **Mod-Friendly Architecture** | Open source — fork, mod, total-convert, or port |

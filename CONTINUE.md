# CONTINUE.md — как продолжать эту работу (промт-эстафета)

Обновлено 2026-08-19 (ночь). Этот файл — вход для ЛЮБОЙ сессии/агента, продолжающих
большую чистку и достройку систем. Прочитал его → прочитал `CANON.md` → открыл нужный
план в `markoaudit/plans/` → работаешь. Владелец держит весь замысел в голове:
**активно спрашивай, обсуждай, предлагай варианты с рекомендацией** — нумерованными
вопросами, на которые можно отвечать односложно. Когда нужна проверка глазами в игре —
прямо зови владельца и давай точный сценарий (консоль-команды, что смотреть).

## Метод (то, что сделало эти двое суток продуктивными)

1. **Канон-первичен.** `CANON.md` (корень) — эталон S1–S11. Вопрос к любому коду: «какой
   системе канона он принадлежит и не вторая ли он реализация». Три исхода: подключить /
   слить / удалить; «оставить как есть» — худший. Код прав, а канон приблизителен? —
   уточнить канон У ВЛАДЕЛЬЦА и записать датированной правкой.
2. **Гейты важнее правок** — список правок кончится, гейт останется. Инфраструктура:
   `tools/check_source_rules.cmake` (9 правил + храповики-базлайны). Новый гейт/тест
   обязан пройти **мутацию в обе полярности** до заявления «ловит» (подсади дефект →
   красный в точной строке; «почини» → храповик требует ужать базлайн).
3. **Пины по наблюдаемому.** game_test/world_test пинят точное число чеков в
   CMakeLists. Двигать только по наблюдаемому прогону, дельту объяснять ИЗ СЛАГАЕМЫХ
   в комментарии у пина и в коммите (образцы там же — вся история переездов записана).
4. **Константа выводится, не назначается** (S11). Владелец сам ловит назначенные числа
   («откуда ты их принял?») — вывод пиши сразу рядом. Часы симуляции — ТИКИ (125 Гц),
   не секунды и не fps: сим работает без рендера.
5. **Агенты — в git worktree**, инкрементные коммиты, полный ctest перед сдачей.
   ЛОВУШКА: worktree иногда ветвится от `137f3052` (линия main с marko-валом) —
   при посадке в `torus` НЕ merge (утащит чужую историю в предки), а cherry-pick или
   пересадка restore-путей; если ветка несёт перегенерированные таблицы (prop_table и
   пр.) — перегенерировать на целевом дереве, не брать её файлы. Образцы посадок:
   `verlet-walkbits-clean` (bf16e8ed), черри-пики 0c83ae67/595c7678 и ламповый
   (конфликт props.csv решён «HEAD-мебель + агентские лампы» + regen).
6. **Проверки, всегда:** `cmake --build build -j 10` → `ctest` (6/6) → гейт печатает
   `GIGA_SOURCE_RULES=PASS`. Перф: `rm -rf gigahrush2_save && ./build/gigahrush2
   --shot /tmp/x.png --floor N --frames 1200` → `[gpu-shot]`/`[cpu-shot]` (MoltenVK:
   верить только frame total, пер-пассовый сплит лжив). Верле: `GIGA_VERLET_PIN=120`
   × 2 прогона = идентичные fnv. Свет: `GIGA_LIGHT_BUDGET=N` для A/B.
7. **Роли:** эта линия — ПРОПЫ/рендер/системы; параллельная сессия владельца — ЭТАЖИ
   (модули-карты, политика расстановки). Не лезть в чужие файлы, пока чужой WIP
   не закоммичен.

## Ключевые законы, добытые в этой сессии (полные формулировки — в CANON.md)

- **S2, закон двух масштабов** (главное открытие): атомы-субвоксели = физическая
  правда; сетка 128³ = макро-каркас; локальный вопрос (луч/тело/опора/скол),
  читающий клетку, — дефект. Все свежие баги — «клетка соврала локально».
- **S4**: CPU/GPU = «дорого/дёшево», связь односторонняя мир→GPU.
- **S9**: бесшовный бейк по построению (циклы, не деревья); допекание = постоянный
  фоновый ПОЛНЫЙ ребейк со свапом (снапшот-битсеты 256 KiB вместо фриза мира);
  SLA в тиках, потолок 8192; самосбор — ОТДЕЛЬНАЯ система (клет-автомат).
- **S10**: модуль этажа = редактор карт; в общем коде нет политики расстановки.
- **S11**: капы — корневые на систему (пропы 131072 / свет 131072 / антураж 2^20 /
  частицы 32k-пул), производные считаются от корня, обрезание молча запрещено,
  «что рисовать» решает каллер видимости.
- **S3**: таблица пропов = набор ассетов (модель опционально, процедурный дефолт);
  лампочка = GpuHandoff (сделано).
- Якоря: способ антуража (клетка+грань+проба колонки атомов) — канонический;
  обобщение WorldAnchor поднимет пропы до него (face станет нормалью крепления).

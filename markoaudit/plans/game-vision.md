# ВИДЕНИЕ ГИГАХРУЩ 2 — со слов владельца 2026-09-01 (+правки продюсера)

## Ядро видения (владелец)

Путешествие между этажами · встречи с разными NPC · лутание · качание
билда через перки и экипировку · самосборы · разрушение этажей ради
секреток и крутых вещей · ~10 часов игры.

**Арка по лору**: в начале — просто жизнь в хруще; выше — всё меньше NPC,
всё больше этажей с мобами, больше сюра; затем мясные этажи, сложные
этажи с жижей/кислотой/лавой/мясом, больше платформинга, риска, мобов;
финал — космик-хоррор.

Движку арка ДЕШЕВА: кислота/лава/мясо = строки materials.csv (флоу,
урон контакта, эмиссив, переходы — таблица переходов уже запланирована
S16); слои арки = модули этажей.

## ⚠ РЕШЕНИЕ ВЛАДЕЛЬЦА ТРЕБУЕТСЯ ДО ЗАМОРОЗКИ (веха В5)

**Перки**: системы прокачки в ядре НЕТ. Рекомендация (а): перки =
ПРЕДМЕТЫ (импланты/стимуляторы строками items.csv, модифицируют
существующий 8-слотовый атрибут-блок игрока-алайфа) — контент, ядро не
трогается, лутаются/продаются/теряются со смертью. Альтернатива (б):
отдельная система с деревом — тогда ВСТАВИТЬ В ОЧЕРЕДЬ до заморозки.

## Правки продюсера (приняты к обсуждению)

1. Первый час: обыденность обязана быть ЗЛОВЕЩЕЙ, не спокойной — тревога
   деталями с первой минуты + слабый учебный самосбор в первый час.
2. Космик-хоррор — через БЕТОН И БЫТ, не лавкрафтиану: квартира игрока с
   чужими вещами, лифт, едущий слишком долго, коридор тором в себя
   (движок умеет буквально). Сюр из обыденного = Самосбор.
3. Финал НЕ в EA: EA = первые 3-4 слоя арки (~10 ч) с крюком; мясные
   этажи и финал — обновления к 1.0. Слои арки = маркетинговый роадмап
   («обновление МЯСО» и т.д. — каждый слой инфоповод).

## Добавления продюсера

1. **РАЗРУШЕНИЕ КАК ОСЬ ПРОКАЧКИ** (уникально, нескопируемо): инструменты
   ломания растут билдом (лом → кувалда → заряды → резак), секретки
   ЗАМУРОВАНЫ В СТЕНАХ, глубина арки требует лучшего инструмента.
   **КАНДИДАТ-ЗАКОН ПОРОГА (обсуждён 2026-09-01, владелец: «оставить
   вероятность + порог по инструменту»)**: carve_roll получает порог
   прочности В ТОЙ ЖЕ формуле, не веткой — p = max(0, E_уд −
   E_порог(hardness)) / квант. Ниже порога — строгий ноль НАВСЕГДА
   (упругий удар не копит повреждений — вот почему полю HP по-прежнему
   незачем существовать), выше — сегодняшний вероятностный режим
   бит-в-бит. Порог выводится из hardness (уже в materials.csv;
   kHardnessUnbreakable = частный случай «порог ∞» — спец-чек гермо
   умирает, унификация), энергия удара — уже закон E=mv²/2, третий
   ингредиент — ПЛОЩАДЬ КОНТАКТА инструмента (одна новая колонка
   items.csv): порог сравнивается с УДЕЛЬНОЙ энергией E/площадь —
   пуля дырявит бетон точечно, кувалда крошит кирпич кусками, кулак
   бетону ничего. Прогрессия = строки двух таблиц. Ниже порога — фидбек
   обязателен (звук/искры/щербинка-стейн): игрок читает «нужен
   инструмент получше». Посадка: одна правка carve_roll + колонка +
   гейт (кулак по бетону 10к роллов = 0 атомов; мутация «порог снят» —
   красная). МЕЛКАЯ, но в ЯДРО — вставить в очередь ДО заморозки
   (кандидат: попутно с agent-goals или щитком).
2. **Смерть через самосбор**: умер → проснулся в своей комнате («дом
   пересобрал жителя»), несомое пропало, слабый след-дебафф. Потеря +
   непрерывность 10-часовой арки + лор одним ходом. (Кандидат ответа на
   вопрос «правило смерти в демо» из release-roadmap.)
3. **Дневники = навигация к секреткам**: записки указывают, где ломать —
   склейка лута, разрушения и сюжета в одну петлю (механика уже есть).
4. **Интенсивность самосбора — параметр модуля** по слою арки (данные).

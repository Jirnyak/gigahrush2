# Единый якорь: одна кодировка грани, одна проба живости

Дата: 2026-08-20. Решения владельца (этот же день): (1) якорный фронт — первым
после световой гигиены; (2) **база — антуражная кодировка** (клетка + 6-значная
грань, проба — колонка субвокселей у грани); (3) «ящик → проп» (S14.1,
`one-container.md` инкременты A-B) берётся сразу же, не ждёт rooms-object.

Дорешено владельцем тем же вечером после обсуждения: (4) **проба — в ТОЧКЕ
крепления**, не в центре грани: окно 2×2 в (u,v) субвокселя якоря (иначе
угловой выключатель живёт по материи в полуметре от себя — класс «клетка
соврала локально» S2); антураж передаёт центр, поведение проводов не меняется;
(5) **футпринт w×h для больших SimpleFall — вторым заходом**, после базы.

Канон: S2 (проба обязана спрашивать колонку у грани крепления, не бит и не
клетку), S10 (`SubVoxelAnchor.face` обязан ожить как нормаль крепления или
умереть), S11 (вторая реализация = дефект), S14 (контейнер якорится к носителю).

Разведка перепроверена по коду 2026-08-20 (все адреса — с этого дня).

## 1. Сегодня: две кодировки, девять мест записи

**A. Пропы — `SubVoxelAnchor`** (`prop_system.h:25-29`): `int cx,cy,cz` + один
субвоксель `subX/subY/subZ` + `uint8 face`, у которого ТРИ несовместимых смысла
(0=пол, 1=стена-без-стороны, 2=потолок) и **ноль чтений** во всём дереве.
Проба живости — ОДИН бит из 512 (`prop_system.cpp:278`), гейт спавна — тот же
бит (`:319`). Улика класса дефекта: сидеры (`room_floor_under`
`room_zone.cpp:460-480`, `lowest_layer_centre` `prop_system.cpp:588-604`)
существуют ровно чтобы удовлетворить побитовый гейт — скан только по Z,
Z-привилегия.

**B. Антураж** (`antourage.h:47-141`): две клетки-якоря + `face = axis*2 +
(dir<0)` — честные 6 значений, субвоксель не хранится. Проба — воздух клетки
ИЛИ `face_layer(axis, dir, true)` по колонке 2×2×8 (`antourage.cpp:775-781`).
Это и есть каноническая форма по S2 (проверена владельцем на проводах).

Сайты записи A (все — под миграцию):
`prop_system.cpp:481-489` (настенные, face=1 на все 4 стороны — направление
восстанавливается из `wxd/wyd` `:474-479`), `:606-614` (потолочные, face=2),
`:325-327` (копия в spawn), `room_zone.cpp:524-531` (мебель, face=0),
`padic_module.cpp:44-95` (лампы падика, face=2 дважды), `container.cpp:357`
(позиционный брейс-инит `{cx,cy,cz,4,4,0,0}` В ВОЗДУШНОЙ клетке мимо
`spawn_prop` — якорь мёртв с рождения, живёт лишь потому, что воздушная клетка
не попадает в dirtyCells; чинится не заплаткой, а `one-container.md` B: ящик
становится пропом и получает честный якорь тем же путём, что все).

## 2. Целевая форма

```cpp
// Якорь = ГРАНЬ опорной клетки. Кодировка граней — антуражная (6 значений,
// antourage_face_pack/axis/dir), проба живости — колонка субвокселей у грани
// (SubMask::face_layer), общая функция anchor_alive(grid, cell, face).
struct SubVoxelAnchor {
    int cx, cy, cz;          // опорная клетка (wrap_macro на входе)
    std::uint8_t face;       // axis*2 + (dir<0): нормаль ОТ опоры К вещи
    std::uint8_t subX, subY, subZ; // субвоксель — только позиция меша, НЕ проба
};
```

- **Проба и гейт спавна меняются ВМЕСТЕ** (`prop_system.cpp:278` + `:319`) на
  ту же колонковую функцию, что у антуража, — вторая проба умирает.
- **`face` оживает дважды**: (а) направление детач-импульса — сейчас берётся из
  гравитации (`prop_system.cpp:288-297`), у антуража уже по грани
  (`antourage.cpp:888-889`); (б) позже — ориентация меша (у пропа сегодня
  только yaw, Z-привилегия из S10). (б) — отдельный инкремент после якоря.
- Субвоксель остаётся в структуре как позиция крепления для меша/отрыва, но из
  пробы уходит.
- Антуражный `AntourageInstance` НЕ перекладывается на этот структ (у него две
  клетки и `uint8`-координаты в бейк-массивах) — общей становится ФУНКЦИЯ
  пробы и кодировка `face`; хранение у каждого своё, как у клетки и маски.

## 3. Инкременты (каждый — зелёный)

1. **СДЕЛАНО 2026-08-20.** `anchor_alive()` — общая колонковая проба, легла в
   `src/world/anchor.h` (не game: якорение — примитив ДВИЖКА по S10), вместе с
   `anchor_face_pack/axis/dir` (переименованы из antourage_face_*, 26 сайтов)
   и `anchor_face_uv` (субвоксель → (u,v) грани; раскладка тангенциальных осей
   живёт в одном месте). В ядре — `SubMask::face_layer_window(axis,dir,u,v)`,
   обобщение центральной колонки до точки крепления; `face_layer(centreOnly)`
   делегирует в него с центром. Антураж переключён; suite_antourage зелёный
   БЕЗ правок ожиданий — проба воспроизведена бит в бит.
2. **СДЕЛАНО 2026-08-20.** face → 6 значений во всех БОЕВЫХ сайтах записи:
   настенные — `anchor_face_pack(осьX/Y, −wxd/−wyd)` (нормаль от стены к
   панели), потолочные (prop_system + оба сайта падика) — `(2,−1)`, мебель —
   `(2,+1)`. Поле пока не читается пробой — чистая перекодировка, словарь один
   с антуражом. Тестовые якоря (`suite_props_game.inl:353,812,990` — face=0
   произвольный) НЕ тронуты сознательно: их face станет значимым и правится в
   инкременте 3, вместе с семантикой.
3. **СДЕЛАНО 2026-08-20.** Проба (`anchor_validate_step`) + гейт спавна →
   `anchor_alive(грань, uv из субвокселя)` одним коммитом; гейт строго шире
   побитового — всё, что спавнилось, спавнится. Новый тест
   `test_anchor_column_probe_both_polarities` (чужой бит и даже свой бит при
   живой колонке НЕ роняют; смерть колонки 2×2 у грани — роняет; пин
   game_test 235848 → 235855). Обратная полярность прогнана ДВАЖДЫ:
   (а) anchor_alive→true — антураж-суита красная массово; (б) точечная
   мутация пропового пути — новый тест красный сам. Из старых тестов
   пересел один: «второе мнение» suite_rooms (`anchorAir`) спрашивает теперь
   словами пробы — расширенный гейт легально пускает мебель с воздушным
   точным битом при живой колонке. Тестовые якоря с face=0 в синтетике НЕ
   тронуты: их сценарии карвят целую клетку, семантика face там не участвует.
3б. **СДЕЛАНО 2026-08-20** (внеплановый, репорт владельца: щиток парит в
   воздухе у лепленой стены). Позиция настенной панели шла из ГРАНИЦЫ клетки,
   проба — из субвокселей: расщепление источников. Сидер теперь спрашивает ту
   же колонку (`face_layer_window` в точке крепления), прижимает панель к
   найденной поверхности (recess в слоях × kVoxelSize) и пишет в субвоксель
   якоря найденный слой, а не «крайний». Пустая колонка = кандидат отброшен.

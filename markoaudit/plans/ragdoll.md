# РАГДОЛЛ — универсальный твердотел пропов

Решения владельца 2026-08-21 (диалог, эта сессия). Метод эпика — его же:
**инкрементально-эмпирически**: каждый шаг тестится владельцем лично в игре
(`spawn_ball` → смотрим → крутим), пока не идеально. План — не контракт на
числа, числа крутятся глазами; контракт — архитектура ниже.

## Решения (зафиксированы владельцем)

1. **Импульсный твердотел, одна универсальная модель.** Не верле: скорость +
   угловая скорость + импульсы в контакте. Выбор владельца: «универсальный
   твердотел лучше, элегантная оптимизированная».
2. **Масштаб — тысячи.** Порядок рагдолл-пропов на активном этаже — сотни и
   тысячи суммарно (граната — всё разлетается; трупы падают; кап у трупов
   приемлем — на этаже до 16k NPC, столько рагдоллов физически не нужно).
   Следствие: **сон — главный механизм**, спящее тело стоит ноль; активны
   одновременно сотни, живут тысячи. SoA, ноль аллокаций в тике (S9/DOD).
3. **Проп-проп коллизия ЕСТЬ: шар-шар через клеточный биннинг** (S9, O(n)).
   Кучи тел и обломков — честные.
4. **Труп стартует ОДНИМ телом**, сегментность («шарики на цепях» — связи как
   ещё один вид констрейнта в том же солвере) выращивается эмпирически, когда
   одиночное тело доведено до идеала. Топологию (цепь 3–5 / дерево 7–9)
   владелец выберет глазами.
5. **Одно физическое ядро на RagdollRoll И SimpleFall.** Три пути пропа (S3)
   остаются интерфейсом; «падает как коробка» — те же уравнения с параметрами
   материала (трение высокое, отскок ~0, инерция коробки). Свепт-AABB для
   ПРОПОВ умирает; для АГЕНТОВ (ходьба игрока/NPC — контроллер персонажа, не
   рагдолл) свепт-AABB в physics_step живёт как жил.

## Модель (ядро)

- Тело: `Transform.pos` + `Velocity.v` (линейка — существующие компоненты,
  рендер-пути не ломаются) + `RigidBody{quat q, vec3 w, invMass, invInertia,
  radius, restitution, friction, сон}`. quat — новый тип в core/math.h
  (Euler для кувыркания не годится).
- Коллизия с миром: **сфера против субвокселей** (S2 — локальный вопрос
  спрашивает атомы; `SubMask` уже источник). Любая форма = набор сфер, жёстко
  посаженных в тело; один шар — вырожденный случай.
- Контакт: sequential impulses — нормальный импульс с restitution (порог
  ~1 м/с, ниже — не скачет, оседает), трение Кулона в касательной **через
  точку контакта** (v_contact = v + w×r) — качение ВОЗНИКАЕТ из трения, а не
  назначается косметикой; трение качения — малый тормозящий момент.
- Параметры — из материала (S11: masse = density_kg_m3 × объём, отскок/трение
  выводятся из hardness; вывод при спавне из строки таблицы, ядро таблиц не
  знает — ест числа).
- Импакт-шов: погашенная нормальная скорость > 4 м/с пишет `Impact`
  (E=mv²/2 — существующий закон, урон от пропов даром).
- Сон: |v| и |w|·r ниже порога N тиков подряд → asleep (v=w=0, тело
  вычеркнуто из интеграции); будят события: взрыв/импульс, карв рядом
  (dirtyCells), касание живым телом.

## Инкременты

1. **Ядро на одном шаре** — quat, RigidBody, интегратор, контакт
   сфера-субвоксель, отскок+трение, сон; BodyInstance получает кватернион
   (вращение ВИДНО — иначе качение неотличимо от скольжения); `spawn_ball`
   переводится на ядро. Тест владельцем: мяч катится, скачет, тормозит,
   засыпает.
2. **Материальные пары** — restitution/трение из пары (тело, субвоксель под
   ним); возможно новые колонки materials.csv (генератор!). Крутится глазами.
3. **Шар-шар** — биннинг по клеткам, куча мячей (`spawn_ball N`).
4. **Миграция RagdollRoll-пропов** — детач-путь пропов и трупов на ядро;
   старая косметика ω=n×v/r в physics_step и prop_ragdoll_step умирают.
5. **SimpleFall на ядро** — набор сфер из габарита строки props.csv (вывод,
   S11); свепт-AABB-ветка для DynamicBodyTag-пропов умирает.
6. **Связи** — шарнир как констрейнт в том же солвере; труп сегментируется,
   топология подбирается глазами. Пробуждение цепи — целиком.
7. **Гигиена масштаба** — SoA-замер на тысячах, кап от корневого пропов
   (131072, S11), сейв (поза не сейвится — тело ложится заново, решение
   владельца в one-container.md), взаимодействие с игроком (толчок/урон).

## Гейты

- Ветка по виду пропа в ядре запрещена: RagdollRoll и SimpleFall различаются
  ТОЛЬКО параметрами (форма сфер, материал).
- Константа без вывода рядом — дефект (S11): масса из плотности, инерция из
  формы, пороги сна из скорости/радиуса.
- Замер после инкремента 3 и 7: 1000 активных тел — слоуп кадра по двум
  `--shot` прогонам, Release, тип билда назван.

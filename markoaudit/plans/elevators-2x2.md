# Лифты 2×2 — диегетическая кабина + фоновая генерация этажа

Записано 2026-08-27 со слов владельца (сессия хрущей). Решения владельца:

1. **Сетка лифтов 2×2 на этаж** — 4×4 слишком плотно. 2×2 = **подмножество
   латтиса 4×4** (каждый второй узел): нав-граф 4×4 НЕ трогается — нав
   использует решётку как Voronoi-декомпозицию и не знает, есть ли в узле
   шахта (проверено разведкой: `nav.h:35` kNodes=64, `nearest` — якорь
   клетки; убирание шахты из узла честно отражается в `edge[][]`).
2. **Лифты ЗАМЕНЯЮТ бескабинный телепорт** (S11: одна система перемещения).
   Правила назначения прежние: этажи, открытые ранее (`FastTravelState`),
   плюс соседние по номерам. Гейт остаётся чистой функцией; `NotOnHub`
   умирает в пользу `NotInCabin`.
3. **Поездка = иллюзия Dead Space** (CANON S9.1): кнопка у шахты →
   кабина приезжает, открывается → игрок внутри выбирает этаж → створки
   закрываются, кабина «едет» (игрок заперт, тряска/звук/табло) → фоном
   асинхронно генерится и печётся целевой этаж → по готовности двери
   открываются уже там. Бесшовная загрузка.
4. **Код — отдельной сессией** по этому плану; хрущи-сессия оставила только
   план и разведку.

## Снятое противоречие

`Docs/specs/16_ELEVATORS_AND_FLOOR_STREAMING.md` §12 запрещал асинхронный
переход («резать стоимость, не видимость»). Владелец 2026-08-27 подтвердил
канон S9.1 (диегетическая кабина с фоновой генерацией) — спека в этой части
ОТОЗВАНА, при посадке эпика вписать в неё надгробие. Решения из
`async-rebake.md:172-196` остаются в силе: кинематографического ПОЛА нет
(как загрузилось — так и открылись двери), nav_cache не включать (игрок
заперт — печём честно на всех ядрах), F9 во время бейка = отмена и загрузка.

## Что уже есть (разведка 2026-08-27, детали в отчёте сессии)

- `RebakeScheduler` (`rebake.h/.cpp`) — асинхронный воркер с отменой,
  снапшотом-по-значению, посекционным свапом, SLA в тиках. Режима
  `Prebuild` НЕТ — но план `async-rebake.md` §5 его уже спроектировал:
  воркер — единоличный владелец строящегося World в нерезидентном слоте
  (`streamer.init(stack, keepRadius=0)` уже держит второй слот пустым).
- `ride_elevator` (`elevator.cpp`) — перенос тела/камеры/оружия/статов,
  посадка по оси гравитации; `fast_travel.h` — гейт с типизированными
  отказами + unlock-битсет в сейве (v10).
- Deferred-request шов (`console.h` → дренаж в топе кадра `main.cpp:3184`)
  — готовая точка старта поездки.
- Тайминги `[floor]`/`[rebake]` — измеримость готова.
- Мёртвые биты `PlayerCommand::ElevatorUp/Down` — шов для netcode-кнопки.
- Крючки контента: моб `PSEUDOLIFT` (ложная кабина!), предметы
  `elevator_access_order`/`lift_scheme`/`hermo_gasket`.

## Чего нет (ни строки)

Состояния «игрок в кабине»; кнопки-интерактива; створок/анимаций (двери —
мгновенное переключение клеток); интерьера кабины; асинхронной генерации
ЧУЖОГО этажа; разреза `ensure_loaded` на world/ecs половины (Registry
небезопасен из воркера — самый рискованный кусок, ~600 LOC); лифтового
звука. Полный перечень — в отчёте разведки.

## Ключевой замер, который нельзя потерять

Доминирует НЕ генерация (~130 мс), а **чтение снимка ревизита
`apply_floor_file` ≈ 6.4 с**. Prebuild ОБЯЗАН покрывать restore-ветку
(файл читает воркер), иначе он прячет 2% работы. Печатать
`[lift] prebuild N: world X ms | ecs Y ms` каждый прогон.

## Дизайн

- **Узлы лифтов**: латтис-узлы с чётными (ix, iy) → шахты на {16, 80}²
  (4 на этаж). Маппинг hub∈[0,4)↔узел — в `fast_travel.h` рядом с
  существующей арифметикой (`kFastHubsPerFloor` станет выводиться из
  лифтовой сетки, не из всей грани решётки).
- **Кнопка вызова** = строка `data/interactables.csv` (LiftCall, reach
  2.5) + проп `lift_button` строкой `props.csv`, сидится модулем этажа у
  шахты (S10: политика в модуле). Самый дешёвый шов эпика.
- **Кабина** = комната-бокс в шахте на уровне земли этажа; кабина НЕ
  движется (движущихся объектов в движке нет и не появляется): «приезд» =
  задержка + звук; створки = DoorState на проёме шахты (мгновенные — до
  отдельного решения владельца об анимации).
- **Поездка**: состояние `InCabin` (игрок заперт: контроллер в бокс),
  выбор этажа — интерактив панели в кабине (тот же экран, что шахтное
  меню L, но диегетически); старт → `RebakeScheduler::Prebuild(target)`;
  иллюзия (тряска камеры, гул из сим-события — звук из физики, табло
  этажей) длится `max(готовность, минимум ~3 с)`; свап → `ride_elevator`
  в кабину целевого этажа → двери Open.
- **Смерть телепорта**: консольные `ft`/`ride` остаются дев-инструментами;
  диегетический путь один — кабина. Пады `kMatHubPad` остаются геометрией
  площадей/лобби.

## Инкременты (для новой сессии)

1. Разрез `ensure_loaded` на world-половину (worker-safe) и ecs-половину
   (main) — билд зелёный, поведение бит-в-бит (это чистый рефакторинг).
2. `RebakeScheduler::Prebuild` — фоновая world-половина в свободный слот,
   включая restore-ветку; замер `[lift] prebuild`.
3. Лифтовая сетка 2×2 в `fast_travel.h` (маппинг хабов) + гейт
   `NotInCabin`; тесты round-trip как `test_fast_travel`.
4. Кнопка + кабина-бокс + `InCabin` + панель выбора; поездка через
   Prebuild; `[`/`]` и `ft` переводятся на дев-статус.
5. Иллюзия: гул (сим-событие), тряска, табло; двери-створки.
6. Модули этажей: лобби/машинное у 4 лифтовых узлов (падик/блейм/хрущи
   каждый по-своему, S10); `PSEUDOLIFT` включить спавном — ловушка готова.

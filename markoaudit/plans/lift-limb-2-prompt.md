## ГЛАВНЫЙ ФАКТ, НА КОТОРОМ СТОИТ ЭТА СЕССИЯ

Диегетический путь игрока УЖЕ едет через лифтовую машину (кнопки кабины →
start_lift_ride → Prebuild-воркер + шаги посадки ПО КАДРУ + створки по
готовности wakes_pending). Строка `[lift] arrive N: ... (sync, one frame)`
печатает только ДЕВ-ШОВ (console ft / --floor / фолбэк отказа prebuild) —
2602 мс владельца были дев-швом. **Машину на обжитом сейве покадрово не
мерил ещё НИКТО** — особенно прибытие ОБРАТНО на жирный этаж 0.

   (shadow copy ~17 + lightvis load ~15 + clearance ~2 + БЕЗЫМЯННАЯ

   235+317 на буте; lightvis 1.0-2.3 с ПЕРВЫЙ вход, пока кэш холодный;
   awaken ~100; take_prebuilt-кадр с teleport+arrive_head).
2. **Резать по именам** — самый жирный кадр первым, бюджет на тик, гейт и

   этажа (есть ли инкрементальная заливка страниц по кадрам?), безымянная
   разбивка на зоны в door_declare/нав-пути, shadow copy (полная копия
   MacroGrid — она «единственная законная», но 17-24 мс в одном кадре).
3. **Меж делом — инкремент B** (решение владельца уже есть): снос обеих
   reach-колонок (props.csv reach_mm + interactables.csv reachM) —

   кандидат на снос по критерию «тест проверяет сам символ»; двинутся

   Генераторы: gen_prop_table.py / gen_interact_table.py, судит

## ЛОВУШКИ (проверены сессией 1)

* lightvis-кэш греется ПО КОНТЕНТУ: первый вход любого нового состояния
  этажа — всегда FRESH-бейк. Мерить ОБА входа (холодный и тёплый);
  `rm -rf gigahrush2_save` убивает и кэш (честно для холодного замера,
  тёплый требует сейв сохранить).
* `[lift] arrive ... (sync, one frame)` — только дев-шов. Машина печатает
  `[lift] swap: ...` и `[lift] ride to N: ... ticks cabin-to-doors`.
* Дев-швы (console ft, --floor, клавиши [ ]) СОЗНАТЕЛЬНО синхронные — это
  прибор замера, не чинить их машиной без решения владельца.
* Пины ctest живут в КОНФИГУРАЦИИ (после правки CMakeLists — cmake
  --build); дельта пина сходится ТОЛЬКО по исполнениям, прогоном бинаря.
* Новые гейты — мутация в обе полярности ДО записи «гейт ловит».
* Кадры ≠ сим-тики; хитч ≠ медиана; счётчик в горячем цикле искажает
  (§86). Мерить на ОДИНАКОВОМ состоянии сейва; generate/restore платят
  разное — обе ветки.
* Отложенный автосейв поездки: run.sav садится по состоянию «хвост
  покинутого этажа лёг» (констант нет); дизарм на leave/F9/F5 — при
  правках вокруг сейвов не сломать порядок закона дюпа.

## ЧЕГО НЕ ДЕЛАТЬ

* Не полировать контент (плотности, раскладки) — «сейчас только СИСТЕМЫ И
  ЯДРО, этажи = примеры для теста систем».
* Не вводить фиксированное время поездки и экраны загрузки.
* Не трогать ящик-хак (бэклог владельца), PowerGridState (ждёт эпика),
  стим-блокеры (EA сдвинулось, даты нет).
* Остаточное легаси потолочной сеялки («потолок = +Z» — нарушение S10,
  ниши, одна-лампа-на-блок, шнур 0.14f) — названо, НЕ брать без отмашки:
  это уже изотропия, отдельный разговор.

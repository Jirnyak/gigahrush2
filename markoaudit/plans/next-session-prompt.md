## МОДЕЛЬ НАСЕЛЕНИЯ — манекены (замысел владельца 2026-09-06, кандидат в канон)

Конвейер модуля этажа (слова владельца): геометрия из субвокселей →
якорение пропов/антуража/ламп → интеракторы → комнаты (3D-боксы) →
дизайн-контент (спец-комнаты/спец-интеракторы, если есть) → **манекены**.

**Манекен = агностичный слот населения**, который модуль ставит на сцену
при генерации, как редактор сцены: «тут будет некий НПЦ, тут некий
монстр» — с контекстом (позиция/комната, роль/условия), но БЕЗ знания,
кто именно. Разрешение происходит НА ВОПЛОЩЕНИИ единым механизмом, и
ОБА пути — из макролайфа: генерик-слот → процедурно подходящая запись;
дизайн-слот (квестовый/сюжетный НПЦ, босс, моб особых условий) →
КОНКРЕТНАЯ запись макролайфа (анкета реестра, plot-spine: сюжетный НПЦ
= запись алайфа). Расстановка — одна система, ветки генерик/дизайн при
расстановке не существует, только селектор заполнения на воплощении
(«агностицизм и изотропия», детали обсудить при посадке). КАК модуль
расставляет манекены — его дело целиком (S10): руками, процедурно, RNG
— «модуль отвечает как обычно» (владелец 2026-09-06).

**Сегодняшний код относительно этой модели — ОШИБКА (вердикт владельца
2026-09-06):** слепой хеш-посев позиций population.cpp + «воплощение
ставит тело на ближайшую проходимую клетку» (place_body_safely как закон
места) — дефект; позиция обязана приходить из слота-манекена, пул
записей остаётся. Раздача якорей agent-goals E = заполнение слотов
(слот в жилой комнате → якорь дома); plot-spine садится на те же слоты.
**Мобы — чисто этажный спавн** (решение владельца 2026-09-06): в
макропопуляции 2^20 их нет, моб проще НПЦ (S13.7), живёт
персистентностью этажа; манекен моба заполняется этажно.

# Словарь глаголов — один язык для предмета, пропа, комнаты и агента

Канон [CANON.md] S12.2–S12.4, решения владельца 2026-08-20.

**Что это даёт.** N агентов × M целей разваливается на N + M: комната не знает про нужды и
статус, агент не знает, из чего сделан бар. Новый фактор поведения = новая функция «контекст
→ добавь столько-то глаголу», и выбор цели при этом не трогается вообще.

## Целевая модель

```
data/verbs.csv        id, терпение(0..1), требует_оболочки(0/1)
      ↓ tools/gen_verb_table.py  →  src/game/verb_table.h   (K берётся из CSV, в коде числа нет)

data/props.csv   + столбцы глаголов: что проп ПРЕДОСТАВЛЯЕТ   (возможность, не тратится)
data/items.csv   + столбцы глаголов: что предмет УТОЛЯЕТ      (ресурс, тратится)
```

```
verbs.csv                    props.csv (новые колонки)
id        терпение           id          глаголы
спать      0.60              bed_cot     спать 17
есть       0.35              stove       есть 12
пить       0.30              table       есть 4, общаться 3
сортир     0.20              bar_stand   пить 19, торговать 11
работать   0.90              workbench   работать 21
лечиться   0.15              toilet_pan  сортир 19
укрыться   0.00              medbed      лечиться 26
обходить   0.90
шататься   1.00              items.csv
общаться   0.85              хлеб    есть 40      патрон   нажива 12
торговать  0.85              аптечка лечиться 60  болтик   — (всё 0)
нажива     0.85
логово     …                 K ≈ 16-24  →  вектор комнаты = 24 значения
```

**Ценность — глагол «нажива»**, а не отдельный канал (решение владельца): скалярное
произведение остаётся единственной операцией выбора. Болтик даёт 0 и не влияет **без единой
ветки-исключения**; ствол за 500 разворачивает мародёра. Считается уже существующей
`inventory_value` (`loot.cpp:151`).

## Куда класть столбцы, чтобы ничего не сломать

- `PropDef` — 32 байта ровно, но `pad0_` (`prop_table.h:74`) и `pad1_` (`:75-76`)
  **свободны**. Флаг «сетевой/автономный» и/или индекс группы ложатся туда без изменения
  размера и без правки `static_assert`.
- Сам вектор глаголов в 32 байта не влезет — он живёт **отдельной таблицей**, параллельной
  строкам (`verbs[propId][K]`), а не полем в POD. То же для `ItemDef`.
- Генераторы правятся в одном месте каждый: `tools/gen_prop_table.py`,
  `tools/gen_item_table.py` (образец расширения — FLICKER-словарь `gen_prop_table.py:55`).

## Инкременты

**A. `verbs.csv` + кодоген + `verb_table.h`.** Только словарь и терпение, ни одного
потребителя. Гейт: `K` в коде не встречается литералом ни разу; дубль id в CSV — ошибка
генерации, а не молчаливая перезапись.

**B. Столбцы в `props.csv`.** Заполнить существующие 9 строк. Гейт: сумма по строке > 0 хотя
бы у одной строки каждого глагола, иначе глагол мёртв — печатать вслух при генерации.

**C. Столбцы в `items.csv`.** 442 строки; заполнять не все — у большинства честный ноль.
Гейт: `нажива` у каждой строки выводится из существующей колонки цены, а не проставляется
руками (S11: константа выводится).

**D. Вектор предложения на комнате.** `Room::declared[K]` (объявляет модуль) +
`Room::supply[K]` (кэш: Σ пропов + Σ предметов + среда + форма + народ). Инкрементальное
обновление по событию — предмет лёг/взят, проп умер, лампа разбита. Гейт: полный пересчёт
и инкрементальный дают **побитово** одинаковый вектор (оракул, как `walk_bits`).

**E. Смерть суррогатов.** `kRoomAffordance`, `intent_room_mask`, `kRoomFieldMask`,
`kRoomRecovery`, `room_restores`, `room_recover` (~166 строк) плюс их тесты
(`suite_rooms.inl:65-113, 643-697`).

## Что перенести из референса дословно

`../gigahrush/src/data/room_affordances.ts` — 15 строк (не 12: SHOP/BAR/MARKET добавлены
2026-08-20), шкала 8..40, отрицательные допустимы (курилка `shelter −4`). Это готовая
калибровка, проверенная тестом формы распределения. Ноль у SHOP в `store` — намеренный
(«лавка не хранилище: товар в неё возят»).

Терпение — `NPC_UTILITY_INTENT_PATIENCE` (`npc_utility.ts:208-223`) целиком, вместе с
формулой порога `58 + p·42`.

**Не переносить:** `unitish()` — авто-детект шкалы по величине; в C++ шкалы обязаны быть
объявлены. И строковые ключи каналов — только `u32`/enum.

# Светящаяся материя: связность топологии вместо позиции

Задача владельца 2026-08-24, по горячим следам его прогона с кистью `neon`.

## Симптомы (глазами владельца)

1. Разрушил неон — **свет от него остался**.
2. Поставил новый неон — **света нет**; поставил ещё один — свет появился.
3. **Фриз на каждом разрушении** неона.
4. Формулировка владельца: «неон-кластер имеет связность через субвоксели, и
   её надо учитывать, иначе его части уничтожаются, а не всё — баги; то же
   при слиянии нескольких. ИСПОЛЬЗОВАТЬ СВЯЗНОСТЬ ТОПОЛОГИИ».

## Диагноз

**Корень: у эмиттера нет устойчивой идентичности.** `bake_material_lights`
пересобирает кластеры с нуля и отдаёт список; стабильные слоты (ae365997)
матчат их **по позиции центроида**. Отломил кусок неона — центроид сместился
— ключ позиции другой — для системы это ДРУГАЯ лампа: старый слот уходит в
надгробие, новая лампа получает новый слот и ждёт полного бейка видимости
(секунды). Отсюда все три симптома разом: «свет остался» (списки клеток ещё
помнят старый слот), «нового света нет» (новый слот в списках не появился),
«второй неон сработал» (к тому моменту бейк успел лечь).

**Фриз** — субвоксельный скан этажа (703b7c86): 284 мс на каждый карв по
светоматериалу, синхронно в кадре.

## Что строить (замысел владельца)

1. **Идентичность из СВЯЗНОСТИ, а не из позиции.** Кластер = связная
   компонента светящихся СУБВОКСЕЛЕЙ (не клеток). У компоненты должен быть
   устойчивый ключ, переживающий изменение формы: кандидат — самый младший
   плоский индекс светящегося атома компоненты (детерминирован, не зависит от
   порядка обхода, не двигается, пока этот атом жив; когда умирает — ключ
   наследует следующий по порядку, что и есть «та же лампа похудела»).
2. **Разрушение = уменьшение, а не пересоздание.** Отломили часть — компонента
   теряет атомы, центроид/радиус/интенсивность пересчитываются, СЛОТ ТОТ ЖЕ.
3. **Разделение и слияние — честно по топологии.** Разбили перемычку — одна
   компонента стала двумя: одна наследует слот, вторая получает новый.
   Срослись — наоборот. Это и есть «использовать связность».
4. **Инкрементальность вместо полного скана.** Пересчитывать только
   затронутые карвом клетки и их компоненты (карв даёт dirtyCells), а не
   128³. Убирает фриз 284 мс.
5. **Интенсивность/радиус — из числа атомов**, а не из числа клеток: половина
   вывески светит вполсилы по построению (S11 — константа выводится).

## Решения владельца 2026-08-24 (дословно, не передоговариваются)

- **Центроид как идентичность — ХАРДКОД И ОШИБКА.** Работать обязано только
  через связность. Формулировка владельца: «сам субвоксель не должен знать,
  что он часть центроида и чего-либо — только соседи, сам материал и
  связность». То есть ключ компоненты выводится из САМИХ АТОМОВ и их
  соседства, а позиция/центроид остаются производными для рендера света, но
  никогда — признаком «та же это лампа или другая».
- **ПРОЗРАЧНОСТЬ ДЛЯ СВЕТА — ОТДЕЛЬНАЯ КОЛОНКА МАТЕРИАЛА**, а не следствие
  эмиссивности. Сейчас теневой луч прощает субвоксель, если тот СВЕТИТСЯ
  (004b013a) — заменить условие на «материал прозрачен». Это даёт стекло
  даром: новая строка CSV с прозрачностью = свет проходит, материя стоит.
  Менять в обоих местах закона разом: `shaders/raymarch.frag`
  (shadow_cell_occluded) и `src/game/light_vis_bake.cpp` (light_ray_passes,
  где сегодня стоит material_emits_light). Колонка — в materials.csv +
  кодоген (эмит в material_props.h и material_surface.glsl), значение
  выведено, не назначено; воздух прозрачен по построению.

## Статус

- **(4) ПОСТРОЕНО 2026-08-24**: `EmitterField` в [game/light_bake.h] — полный
  субвоксельный скан 128³ платится один раз при постройке этажа; карв и кисть
  `neon` латают поле по своим dirtyCells (O(задетых ячеек)), кластеризация
  обходит только светоячейки. Патч заодно стал детектором «задет ли свет» —
  субвоксельно честным: прежний `carve_touches_light_material` спрашивал только
  тип ячейки и не видел неон, нарисованный атомами (часть симптома «свет
  остался»). Пины: патч ≡ полный скан, одиночный светящийся атом виден патчу;
  обе мутации (не убирает / не добавляет) прогнаны — тест ловит.
- **(1)+(2)+(3) ПОСТРОЕНЫ 2026-08-24**: идентичность — из связности.
  Кластер = связная 6-компонента светящихся АТОМОВ (не клеток, закон S2);
  EmitterClusters хранит атом→id, наследник прошлой компоненты — компонента её
  самого младшего выжившего атома (похудение хранит id; разделение отдаёт id
  части с младшим атомом; слияние берёт младший id, прочие — надгробия).
  Матчинг по центроиду ВЫРЕЗАН (light_pos_key удалён, g_bakedSlotByPos →
  g_bakedSlotById). Найден и убит второй корень «света остался»: карв чистит
  только МАСКУ присутствия (remove_key), материал страницы живёт до опустения
  клетки — бейк, спрашивавший одни материалы, считал выбитые атомы светящимися;
  теперь светящийся атом = присутствует ∧ материал светит, и радиус/центроид
  считаются по атомам. Пины: похудение/разделение/слияние/атомная связность/
  маска; 4 мутации прогнаны, тест ловит все.
- **§5 ЯРКОСТЬ ИЗ МАТЕРИИ ПОСТРОЕНА 2026-08-24** (решение владельца: «от
  материи, но элегантно, НЕ линейно — гигантский билборд не должен выжигать»).
  Вывод: каждый атом излучает одинаково, эмиттер прозрачен своему свету ⇒
  СУММАРНАЯ мощность линейна от атомов; но intensity шейдера — ПИК спада
  (1−d/R)², мощность такой лампы ∝ пик·R³, поэтому пик выводится:
  I = I_табл · (атомы/512) · (R₁/R)³, якорь R₁ — лампа из одной полной ячейки.
  Пределы по построению: воксель-свечка тусклее вывески; билборд не выжигает
  (пик размазан по охвату), но достаёт дальше и суммарно светит больше;
  половина атомов при том же охвате — вполсилы. Пины + 2 мутации формулы.

# ДОРОЖНАЯ КАРТА К РЕЛИЗУ — Early Access в Steam (минимальное демо)

Записана 2026-09-01 по запросу владельца. Не даты, а ЭПИКИ-СЕССИИ с
зависимостями и критериями готовности; темп конвейера известен по факту
(эпик уровня verlet-merge/rooms-object = 1-2 сессии).

## Формула EA-демо (рекомендация)

**Вертикальный срез, а не масса**: 10–15 ОТЛИЧНЫХ этажей + одна короткая
сюжетная цепочка + живой алайф + самосбор как событие-столп + бесшовная
лифтовая петля. Ставка «100 этажей агентами» — это КОНТЕНТ-ПОТОК ПОСЛЕ
релиза (идеальный EA-формат: «новые этажи каждую неделю»), а не порог
входа. Игровой цикл демо: спуск/подъём по тору → выживание (еда/вода/сон
— есть) → лут/бартер (есть) → бой (есть) → события самосбора → сюжетные
крючки → смерть и её цена (решить правило: пермадез слота? возрождение в
своей комнате? — вопрос владельцу на контент-фазе).

## ФАЗА 0-3: доведение и заморозка ядра (очередь уже записана)

1. **agent-goals** (+витнес-минимум, ИИ-бросок) — мир оживает. САМЫЙ
   рискованный по итерациям балансировки — закладывать 2-3 сессии.
2. **Самосбор полный цикл** — хоррор-столп.

## ФАЗА 4: контент-спринт демо — КОНКРЕТНЫЕ ШАГИ (модули+данные, ядро закрыто)

### 4.1 Квест-движок ужатый (эпик, 4 инкремента с гейтами)

1. **Впрыск спроса**: API `quest_inject(npcHandle, verb, amount, expiry)`
   поверх S13-скорера (слагаемое суммы, НЕ приказ — канон S13.2);
   таблица `data/quests.csv`: id, stage, giverPlotId, verb-цель,
   предмет-состояние, условие перехода, next. Гейт: квестового NPC
   перехватывает лопнувший мочевой (приоритет честный, мутация «впрыск =
   приказ» красная).
2. **Состояние в предметах**: дневник/записка = строки items.csv с
   payload (текст+stage); чтение существующим UI осмотра. Гейт: смерть
   квестора → дневник в его луте → цепочка продолжается с любого
   участника (закон plot-spine «любой квест проходим»).
3. **Камера-катсцены**: разведка рефа ../gigahrush субагентом (как там
   сделано, взять лучшее — приказ владельца); полёт камеры ДАННЫМИ
   (ключи позиция/взгляд/время в csv), баблы реплик поверх speech;
   влёт Doom-3 при старте этажа. Гейт: катсцена играется из данных без
   единой правки движка; скип по Esc.
4. **Сейв посреди цепочки**: stage в предметах уже персистентен —
   гейт round-trip.

### 4.2 Сюжетная цепочка №1 (контент, владелец = сценарист)

1. ВОПРОС ВЛАДЕЛЬЦУ: бит-лист сценария (5-7 стадий, 3-4 этажа, финал-крюк
   на EA-продолжение) — надиктовать, я раскладываю в quests.csv +

2. Посадка стадий + катсцены входа/финала; плейтест-приёмка целиком.
3. ВОПРОС ВЛАДЕЛЬЦУ (до этого дойти): правило СМЕРТИ игрока в демо —

### 4.3 Этажи демо ×10-15 (обкатка агентского конвейера)

Процесс на КАЖДЫЙ этаж (день-цикл):
1. Идея-однострочник от владельца («затопленный техэтаж», «рынок»,
   «лазарет после самосбора»...).
2. Агент пишет модуль по туториал-модулю (только SDK).
3. floor-lint автоматом: нав-связность лифт→≥90% комнат; плотности
   лута/спавнов/света в диапазонах от verbs-деклараций; перф-бюджет
   кадра этажа (замер --shot, порог из паспорта); 8 скринов ракурсов.
4. Скрин-серия владельцу → вердикт/правки → мердж.
Первые 3 этажа — вручную со мной (калибровка линта и туториал-модуля),
дальше поток. Definition of Done №7 закрывается здесь.

### 4.4 Онбординг (контент этажа-старта, не система)

1. Спавн-этаж: последовательность первых сигналов домом — свет/табло/
   гудок → первый NPC по делам → первая дверь → первый лут → голод
   заметен → лифт. Без текста; максимум — надписи мира (таблички).
2. Плейтест «чужими глазами» (не владелец): доходит ли до лифта без
   подсказок. Итерации.

### 4.5 Баланс выживания (данные, телеметрия)

1. Телеметрия-лог сессии (локальный csv: голод/жажда/сон/рубли/этаж/
   смерти по времени) — 20 строк в существующий лог, не система.
2. Час реальной игры владельца + плейтестеров → крутить клоки/цены
   СТРОКАМИ (items/verbs/needs-константы уже данные).

### 4.6 Звук (после аудита слепой зоны в фазе 3)

1. По результатам аудита: список дыр. Минимум демо: амбиент-луп на ТИП
   модуля (данными), сирена самосбора (уже ревун щитка), шаги/бой по
   материалам (закон «звук из физики» — проверить полноту), лифт, UI.
2. Ассеты — заказ/генерация; подключение строками (как всё).

## Критерии готовности EA (Definition of Done)

1. Новый игрок доходит до третьего этажа без объяснений вслух.
2. Час сессии: fps стабилен (soak-паспорт), ноль крашей на трёх машинах.
3. Самосбор пережит хотя бы раз за первый час — и он страшный.
4. NPC-мир читается как живой (толпа по делам, перестрелки границ,
   реакция на самосбор) — приёмка глазами владельца.
5. Сюжетная цепочка проходима, смерть квестора не ломает её (закон
   «дневник у любого участника»).
6. Сейв/загрузка идемпотентны на замороженном формате.
7. Конвейер этажей доказан: ≥3 демо-этажей сделаны агентами через
   floor-lint без правок ядра.

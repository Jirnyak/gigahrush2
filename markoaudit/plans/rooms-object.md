# Комната как ОБЪЕКТ — фундамент под S12/S13/S14

Решения владельца 2026-08-20, канон [CANON.md] S12. Заменяет и поглощает `rooms-3d.md`
(тот описывал только «боксы вместо колонн»; здесь — весь предмет целиком).

**Почему это первый эпик.** Сегодня комнаты не существует как вещи. Есть чистая функция
`floor_room_mask(kind, number, rx, ry)` (`floor_gen.cpp:144-166`) — хеш без `z`, без
идентичности, без хранения. Пока нет `RoomId`, к нему нечего прицепить: ни вектор
предложения (S12.4), ни запас (S12.5), ни владельца (S14.3), ни репутацию (S13.6), ни
микроуровень (S13.4). Все остальные эпики упираются сюда.

## Целевая модель

```
struct Room {                       // объявляет модуль этажа при генерации (S10, S12.1)
    RoomId    id;
    Box       boxes[N];             // 3D-бокс в КЛЕТКАХ или композиция (Г-образные, двухсветные)
    u16       tags;                 // авторские метки: nest, hermetic, yakov_lab  (S12.2)
    u16       owner;                // NPC или фракция — одно поле на 3 механики (S14.3)
    i16       declared[K];          // ОБЪЯВЛЕНО: неразрушимая часть предложения (S12.4)
    i16       supply[K];            // кэш: оснащение + запас + среда + форма + народ
    RoomRep   reputation;           // одна запись на комнату, с выцветанием (S13.6)
};

roomAt[cell] : u16                  // 128³ × 2 Б = 4 МиБ на этаж
```

`roomAt[]` — **единственный шов**, и он отвечает сразу на четыре вопроса: в какой комнате
агент, чьей комнате принадлежит контейнер, куда упал труп, какая комната у клетки карва.
Он же делает ненужными 11 полей потока по 2 МиБ — на балансе **экономия 18 МиБ на этаж**.

## Инкременты

**A. `RoomId` и `roomAt[]` живут рядом со старым.** Новая структура + индекс, заполняемые
из сегодняшней решётки (`floor_room_mask` как временный источник боксов: каждая ячейка
4×4×высота_этажа → один бокс). Старое не трогается, ничего не переключается. Гейт: сумма
клеток по всем боксам == числу непустых клеток `roomAt`; ни одна клетка не принадлежит
двум комнатам.

**B. Модуль объявляет боксы.** `FloorDef` получает `rooms` (список боксов + теги +
владелец). Падик отдаёт свои BSP-комнаты вместо выбрасывания (`padic_gen.cpp:169-199` уже
собирает `std::vector<Rect> rooms` — они просто умирают в конце `build_plan`). Гейт:
падик-этаж объявляет ≥ 1 комнату, ни один бокс не выходит за 128³, боксы не пересекаются.

**C. `roomAt[]` печётся в `RebakeScheduler`.** Секция рядом с `rooms` (`rebake.cpp:77-83`,
`:138-146`), тот же посекционный своп. Замер: `[rebake] roomAt N мс` — ожидается быстрее
нынешних `rooms ~0.1 s`, потому что это один проход по боксам, а не 11 BFS.

**D. Потребители переезжают на `RoomId`.** По одному, каждый с зелёным ctest:
`mob_spawn.cpp:271,337`, `container.cpp:345`, `door.cpp:75-83` (гермозона → тег),
`item_table.cpp:3159`, `room_zone.cpp:508`. Гейт: `floor_room_mask` теряет всех
вызывающих.

**E. Смерть старого.** `floor_room_mask`, `floor_room_stride`, `floor_room_bit_index`,
`RoomBit`, `flow[11]`, `nearRoom[11]`, `bake_near`, `bake_flow`, `room_route`,
`kRoomFurniture`, `seed_room_furniture`, вторая решётка `population.cpp:22-32`. Замер:
пиковая память этажа падает на ~18 МиБ.

## Гейты

1. **Изотропия**: тест поворачивает объявление комнаты по осям (x↔y↔z) и требует
   идентичного поведения `roomAt`. Сегодняшняя колонна такой тест провалит — это и есть
   доказательство, что 2D умерло.
2. **Ни одной клетки в двух комнатах** и ни одной комнаты без клеток.
3. **`floor_room_mask` не имеет вызывающих** — грепом в `check_source_rules.cmake`.
4. Мутация в обе полярности до записи «гейт ловит» ([[cmake-text-gate-traps]]).

## Риски

- **Сейв.** `roomAt` не сериализуется (перепекается при входе), но `RoomId` попадает в
  якоря агентов (S13.6, S13.8) и в ключ контейнера (S14) — а значит **обязан быть
  устойчив между сессиями**. Источник устойчивости — объявление модуля, не порядок обхода.
- **1024 комнаты на этаж × 255 этажей = 261 тыс.** — авторская раскладка невозможна
  (`Docs/specs/08:401-412`). Модуль объявляет комнаты **процедурно**, а не руками;
  именованные — исключение (`../gigahrush/src/gen/named_rooms.ts` как образец).
- Кап комнат на этаж — корневой по S11, выводится от геометрии, не назначается.

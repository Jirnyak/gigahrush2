# МАСКИ ЭТАЖА (S18): единый MaskGroup — щит и дверь как два свойства

Решения владельца 2026-08-28 (диалогом, поверх канона S18):

1. **Единый носитель MaskGroup строится СРАЗУ, оба переезжают.** Держать щит
   битсетом и дверь порталами = «четвёртый исход» канона. `ProtectMask`
   становится КЭШЕМ предиката над группами (как CellType над маской — лестница
   S2), `DoorPortal` умирает в пользу группы.
2. **Субвоксельность у ВСЕХ масок, включая щит.** Уточнение владельца тем же
   днём: щит — ЧИСТО для гермо и лифтов (гермостены/гермокомнаты/гермодвери,
   лифтовые столбы), не общий инструмент; субвоксельность нужна, потому что
   гермостенка бывает тоньше клетки. Горячий путь карва не дорожает:
   клеточный битсет-кэш «в клетке есть щит-биты» остаётся O(1)-отсевом
   (промах = обычный карв), спуск в субвоксели — только при попадании; оба
   потребителя (`remove_key`, `convert_nodes` в destruct.cpp) уже держат
   индекс атома в руках.

## Носитель (world/mask.h — world-слой, потому что карв спрашивает)

```
MaskCell  { u32 ci; SubMask allow; }        // «эти субвоксели мои» (форма)
MaskGroup { u8 props;                       // kMaskShield | kMaskDoor
            CellType mat;                   // ЧЕМ (двери; 0 у чистого щита)
            u8 mechanism;                   // машина-владелец (лифт)
            vec3 centre;                    // представитель для прицела (выведен)
            vector<MaskCell> cells; }
FloorMasks{ vector<MaskGroup> groups;
            // кэши (rebuild после объявления):
            битсет по kMacroCells «есть щит-биты»           — O(1) гейт
            sorted vector<(ci, merged SubMask)> щит-битов   — bsearch на хите }
```

Семантика свойств (потребители спрашивают, маска не толкает):

* **SHIELD**: писатель геометрии не убирает атом с allow-битом. Оба писателя —
  `remove_key` и `convert_nodes`.
* **DOOR**: закрыть = штамп mat в СВОБОДНЫЕ субвоксели ВНУТРИ allow (чужая
  материя обтекается — закон S17 сохраняется дословно); открыть = снять биты,
  где материал == mat, внутри allow. Решётка/люк = allow не-полной формы.

Законы S18 без изменений: кладёт модуль на генерации; не в снимке
(перештамповка обеими ветками, в сейв едет только материя); активация
отдельно — интерактор ссылается на группу.

## Инкременты

1. **Щит → группы.** world/mask.h; `World::protect()` умирает, floor_gen
   штампует лифтовые столбы группами; destruct спрашивает кэш. Гейт:
   частичный щит в клетке — незащищённая половина карвится, защищённая нет.
2. **Дверь → группы.** door.{h,cpp} поверх MaskGroup (`Doors.list` =
   группы), focus/main/save/rebake/light_vis на новую запись; suite_doors
   пинит то же поведение + дверь-решётка в один субвоксель.
3. **Активация ссылкой**: кнопка-проп несёт group id (вместе с хвостом
   «кнопка лифта снаружи»).

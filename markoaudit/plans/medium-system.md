# Среды — GPU-автомат материи (S16)

Эталон — [CANON.md] S16, записан с диалога с владельцем 2026-08-21. Четыре решения
владельца зафиксированы там: континуум параметров вместо фазы; субвоксели 1024³ с
плотным хранением и брик-обновлением; осевшие обломки снова геометрия (грид один);
обратная связь агрегатами на клетку 128³.

## Что уже есть (эпик — объединение, не стройка с нуля)

| Актив | Где | Что берём |
|---|---|---|
| CPU клеточная жидкость | `src/sim/fluid.cpp/.h` | контракт: масса-сохранение, двухбуферность, детерминизм, `moved`-наблюдение для рендера; логика «вниз → растечься» |
| GPU газ-автомат | `shaders/gas_sim.comp` | скелет compute-пасса: изотропный downStep пуш-константой, VoxelMirror-классификация, probe-ридбек |

| Таблица материалов | `data/materials.csv` + кодоген | `density_kg_m3` уже есть; воздух = материал 0 |

## Инкременты

Каждый — зелёное дерево, руками владельца проверяемый в игре.

### 1. Таблица: колонки текучесть/диффузия

`materials.csv` + `gen_material_table.py` → колонки `flow` (0..1, 0 = твёрдое) и
`diffusion` (0..1). Значения вывести: вода из вязкости, бетон 0, туман из скорости
расползания. Эмитится в materials.h и в GLSL-заголовок (путь кодогена уже возит
константы в шейдеры). Кода сима ноль — чистый фундамент.

### 2. Грид среды + автомат (ядро эпика)

- SSBO 1024³ × u8 материала (~1 ГиБ), заливка из мира при входе на этаж
  (SubMask + SubField sub_material → материал; пусто → воздух).
- **Брик-менеджмент**: брик = клетка (8³ субвокселей = 512 Б). Живой список бриков
  (растёт от писателей и от соседей движения, спит по неподвижности N подтиков).
  Indirect dispatch по списку — полоса платится только за живое.
- Одно правило (двухбуферное, checkerboard для детерминизма): падение по downStep
  фрейма, если `flow==0` — только падение без опоры; иначе растекание ∝ flow;
  `diffusion>0` — расползание; плотность < воздуха — всплытие.
- Писатели: эмиттер (NPC писает, лопнувшая труба, кровь из раны) и карв (вырезанные
  субвоксели → материя среды вместо испарения).
- Дебаг-вид (`GIGA_MEDIUM_DBG`): подсветка живых бриков + счётчик в худе.
  **Печатать числа каждый прогон**: живых бриков, мс автомата, суммарная масса
  (масса-сохранение — это тест, а не надежда).
- Проверка владельцем: вылить воду на этаже 5, лужа находит уровень; моча копится.

### 3. Агрегаты 128³ и потребители

- Редьюс-пасс: на клетку — уровень жидкости, концентрация по материалам-газам
  (топ-K или по маске «газовых» строк таблицы), ридбек как у probe.
- Поля `fluid`/`gas` кормятся агрегатами; `fluid_step`/CPU-сим умирает
  (потребители поля не меняются — S13.3 полевые цели живут).
- Тела: намокание, «в газе X» (bool + концентрация) из клетки тела; эффекты —
  строки данных (газ → урон/стамина), не спецсистемы.
- `gas_sim.comp` умирает: его 4 канала становятся 4 строками materials.csv.

### 4. Осевшее → геометрия (GPU→CPU)

- Брик, уснувший с твёрдым материалом, синхронизируется в SubMask/SubField
  (готовый формат — тот же, из которого заливались). Дальше всё существующее само:
  коллизия, нав-допекание (S9 фоновый ребейк), свет, карв.
- Проверка: обвалить лестницу — завал лежит, по нему ходят, его карвят, он
  НЕ исчезает.

### 5. Рендер сред

Вода/туман/лужи: марш среды в существующем субвоксельном рендере + дымка для
газов. Отдельный разговор с владельцем перед стартом (открытое в S16).

## Развилки, решаемые замером (не владельцем)

- **Бинарный субвоксель против количества 0..255** — построить бинарный (проще,
  1 байт), показать владельцу лужу; если ступеньки уровня 0.25 м режут глаз —
  замерить вариант с количеством.
- **Частота подтика** — вывести из скорости падения (0.25 м/подтик), не назначать.

## Риски

- **Полоса**: 1 ГиБ трогать нельзя — всё через живые брики; кап живых бриков
  корневой, переполнение печатается вслух (S11).
- **GPU→CPU синхронизация** (инкремент 4) — самый дорогой шов; изолирован в
  отдельный инкремент, среды полезны и без него (1-3).
- **Сейв**: материя среды — часть мира; формат сейва этажа получает грид среды
  (сжатие: брики-отличия от залитого — почти всё совпадает с геометрией).

# Мир-автомат (S16) — материя и её единственный двигатель

Эталон — [CANON.md] S16, записан с ДВУХ диалогов с владельцем 2026-08-21. Ключевые
решения владельца: мир = автомат (не «слой сред» — та формулировка снята в тот же день
как второе хранилище материи); GPU compute — осознанная часть ядра, headless = «без
окна», не «без GPU»; фазы нет — континуум параметров материала; осевшие обломки снова
геометрия; связь с телами — агрегаты на клетку 128³; самосбор — программа правил над
тем же гридом (механика бесплатна, режиссура своя); carve — писатель грида, материя
не испаряется.

## Почему эпик дешевле, чем звучит

`render/voxel_mirror.h` УЖЕ возит весь субвоксельный мир на GPU: маски SubMask дословно
(uint[16]/клетку), CellType, страницы `sub_material` **слот-в-слот с CPU-пулом**,
O(dirty-клеток) инкрементальный апдейт от карва и дверей. Об него уже коллизятся частицы
и верле, по нему маршит DDA-рендер. Эпик не строит грид — он **оживляет существующее
зеркало**: даёт ему автомат и обратный поток. Слот-в-слот формат делает GPU→CPU
байт-копией, не трансляцией.

Прочие активы: `fluid.cpp` (контракт правила: масса-сохранение, двухбуферность,
детерминизм, `moved`-наблюдение), `gas_sim.comp` (изотропный downStep пуш-константой,
probe-ридбек), `destruct.h` (карв уже знает материал вырезанного — готовый писатель),
`materials.csv` (`density_kg_m3` есть; воздух = материал 0).

## Инкременты

Каждый — зелёное дерево, проверка владельцем в игре.

### 1. Таблица: колонки текучесть/диффузия

`materials.csv` + `gen_material_table.py` → колонки `flow` (0..1, 0 = твёрдое) и
`diffusion` (0..1); эмит в materials.h и GLSL (путь кодогена уже возит константы в
шейдеры). Значения вывести, не назначить (S11): вода из вязкости, бетон 0, туман из
скорости расползания. Кода сима ноль.

### 2. Автомат на зеркале (ядро эпика)

- Compute-пасс над буферами VoxelMirror + **рабочий пул живых бриков**: живой брик =
  клетка, распакованная в плотные 512 Б (8³ × u8 материала) на время движения; спящие
  клетки остаются в каноническом формате маска/страница. Кап пула корневой,
  переполнение печатается вслух (S11).
- Правило одно, двухбуферное, checkerboard: падение по downStep фрейма; `flow==0` —
  только падение без опоры (обломки); иначе растекание ∝ flow; `diffusion` —
  расползание; плотность < воздуха — всплытие.
- Писатели будят: карв, эмиттеры (моча/кровь/труба) — dirty-клетка + wake.
- Headless: автомат гоняется Vulkan compute **без окна** — тест масса-сохранения и
  «вода находит уровень» в ctest (устройство без свапчейна).
- Дебаг `GIGA_MEDIUM_DBG`: подсветка живых бриков; печатать каждый прогон: живых
  бриков, мс автомата, суммарную массу.
- Проверка владельцем: вылить воду на этаже 5 — лужа находит уровень; моча копится.

### 3. Обратный шов GPU→CPU

Уснувший брик пакуется назад в маску/страницу и байт-копируется в CPU-канон (формат
слот-в-слот — трансляции нет); CPU применяет через существующие dirty-контракты, дальше
всё само: коллизия, нав-допекание (S9), свет. «ONE-WAY FLOW» в voxel_mirror.h умирает
как строка и как ограничение. Допуск канона: материя в полёте видна CPU с отставанием
до кадра.

Проверка: обвалить лестницу — завал лежит, по нему ходят, его карвят, он НЕ исчезает.

### 4. Агрегаты 128³ и потребители

- Редьюс-пасс: на клетку — уровень жидкости, концентрации газов; ридбек как probe.
- Поля `fluid`/`gas` кормятся агрегатами; `fluid_step` умирает (или сжимается в
  CPU-твин для тестов — открытое канона), `gas_sim.comp` умирает: 4 канала → 4 строки
  materials.csv.
- Тела: намокание, «в газе X», плавучесть/сопротивление — из клетки тела; эффекты —
  строки данных, не спецсистемы. Полевые цели S13.3 получают среды даром.

### 5. Carve-унификация

Вырезанное → рыхлая материя в гриде (вместо испарения); пул частиц остаётся косметикой
осколков. Швабра/уборка = карв по материи среды.

### 6. Рендер сред

Поверхность воды, объёмный туман — марш по тому же зеркалу + дымка. Отдельный разговор
с владельцем до старта (открытое S16).

Самосбор-программа — свой эпик ПОВЕРХ этого (режиссура перестройки; механика готова
после инкремента 3).

## Развилки, решаемые замером (не владельцем)

- Бинарный субвоксель против количества 0..255 — построить бинарный, показать лужу;
  ступеньки 0.25 м режут глаз → мерить количество.
- Частота подтика — вывести из падения 0.25 м/подтик; вязкие среды шагают реже.
- CPU-твин правила для ctest без GPU — решить на инкременте 2 (открытое S16).

## Риски

- **Слоение зависимостей**: `giga_core` не включает Vulkan (AGENTS.md, уточнение
  2026-08-21) — автомат живёт compute-библиотекой, ядро видит интерфейс; спроектировать
  на инкременте 2 до кода.
- **Полоса**: трогать только живые брики; спящая материя бесплатна на обоих
  процессорах.
- **Сейв**: канон сериализуется как сегодня (CPU-вид); материя в полёте на сейве
  осаждается или пишется бриками-отличиями — решить на инкременте 3.
- **Детерминизм**: checkerboard + целочисленная материя; эквивалентность прогонов
  гейтится тестом масс-инварианта.

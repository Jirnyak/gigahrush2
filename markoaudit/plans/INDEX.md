## Правила, общие для всех эпиков

- Один владелец билда; агентам — только read-only разведка (AGENTS.md).
- Каждый гейт **мутировать в обе полярности** до записи «ловит».
- Константа выводится, вывод пишется рядом (S11). Владелец ловит назначенные числа.
- Никаких битов-флажков под механики (владелец 2026-08-23): новая механика обязана
  рождаться из параметров данных эмерджентно, как разруб трупов из единых якорей.
- Стоп — только на зелёном ctest, с точным планом продолжения.

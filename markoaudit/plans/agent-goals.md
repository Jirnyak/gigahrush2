## Целевая модель

```
score(агент, цель) = Σ спрос[глагол] · предложение[глагол]
                   − путь − толпа − опасность − чужая территория
                   + связь (дом / работа / любимое / ненавистное / репутация / давно не был)

цель ∈ { комната | сущность | точка | поле }      — все четыре судятся ОДИНАКОВО
различаются только: как дойти  и  что считать прибытием  (таблица, не if)
```

Кандидаты: комнаты — все в выведенном радиусе `R = maxИнтерес / стоимость метра`; сущности
и предметы — **только воспринимаемые** (`Perception`, `los_clear`, поле шума); точка под
ногами — **всегда**, поэтому список не бывает пустым и фолбэк не нужен; полевые — из
`fields()`.

## Гейты (переносить из референса — там они уже написаны)

1. **Форма распределения** (`../gigahrush/tests/room-balance.test.ts`): сытые расходятся —
   комнат в гистограмме ≥ 4, самая людная ≤ 60 %. Ни один канал не перетягивает толпу.
2. **Нужда ведёт уверенно**: доминирующий тип собирает ≥ 75 %.
3. **Ничью решает физика**: четыре одинаковые кухни по углам — ≥ 85 % идут в свою
   ближайшую, и все четыре кому-то цель.
4. **Джиттер личности разводит ровную ничью**: две симметричные кухни делят толпу, меньшая
   доля ≥ 25 %.
5. **Толпа отталкивает**: забитая ближняя проигрывает пустой дальней 12 из 16.
6. **Отбор физический, а не по началу массива**: 200 пустышек в начале — **ровно 16 из 16**
   идут в дальнюю правильную. Жёсткое равенство.
7. **Терпение**: `patience(укрыться)==0`; `порог(работать) > 90`.
8. **Лопнувший мочевой рвёт путь, лёгкий голод — нет**: 16/16 против ≥ 14/16.
9. **Нет коридорных аттракторов** (P0 референса): 120 симулированных секунд, ≤ 6 человек на
   одной коридорной клетке, развороты A-B-A ниже порога.
10. **Грепом: ни одного `if` по виду цели и ни одной ветки «ничего не найдено».**

## Грабли референса — не повторять

- `positive(target.utility)` **съедает отрицательный бонус территории**: `-22` за чужую
  комнату обнуляется клампом (`npc_utility.ts:1123`). Бонус и штраф — два поля.
- `gotoRoom(world, e, roomId)` принимает **id туда, где ждут RoomType** — берёт
  `roomsOfType(type)[0]`, то есть первую по массиву. Два живых вызова.
- Ключ сортировки `round(d2) * 262144 + id` в C++ обязан быть **int64**.
- Мёртвые данные: колонка `hide` не читается нигде; `context.target`/`targetPenalty` —
  оттестированный блок, который в проде никто не заполняет; липкость **цели** мертва
  (`stickiness`/`currentTargetId` не задаются), живёт только липкость пути.
- Смешение единиц: `_barkTime` в секундах, `clock.totalMinutes` в минутах.

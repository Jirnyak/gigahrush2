# 00b — Константы без вывода и мёртвые значения перечислений

## Константы: 504 из 695 — голый литерал

Скан всех `constexpr <numeric> k<Name> = ...;` в `src/`:

| Форма правой части | Штук | Доля |
|---|---|---|
| Голое число (`= 0.6f;`, `= 128;`, `= 900;`) — ни одной ссылки на другую величину | **504** | **72 %** |
| Выражение / ссылка на другую константу (`= kCellSize * 4;`) | 141 | 20 % |
| Прочее (строки, инициализаторы массивов) | 50 | 8 % |

Правило владельца — константа обязана выводиться из свойств объекта, а не назначаться от
балды — нарушено в 72 % случаев. Это не оценка «на глаз»: критерий механический — есть ли
в правой части хоть одна ссылка на другую именованную величину.

Совпадение с картой мёртвого кода прямое: `ai.h`, `needs.h`, `mob_behaviour.h`,
`samosbor.h`, `rpg.cpp` — те же модули, чьи функции никто не вызывает. Неподключённая
система не имеет обратной связи, которая заставила бы вывести число; поэтому число
назначается. Невыведенная константа — не отдельный дефект, а симптом отсутствия
потребителя.

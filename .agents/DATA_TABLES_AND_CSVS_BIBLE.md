## 1. CSV КАК ЕДИНСТВЕННЫЙ ИСТОЧНИК ПРАВДЫ (SINGLE SOURCE OF TRUTH)

1. **Железный закон данных:**
   - Весь игровой контент — предметы, монстры, мебель, части тел, физические материалы, глаголы действий — определяется **исключительно** в таблицах CSV (`data/*.csv`).
   - Исходный код C++ (`src/`) **никогда не содержит захардкоженных списков сущностей, характеристик урона, цен или весов**.
   - Добавление новой вещи, оружия или монстра в игру — это **добавление одной строки в CSV** и прогон генератора, а не правка движка.
2. **Тотальный запрет на ручное редактирование сгенерированного кода:**
   - Файлы `src/game/item_table.cpp`, `src/game/mob_table.cpp`, `src/game/prop_form_table.cpp`, `src/game/action_table.cpp` являются **автоматически сгенерированными производными артефактами**.
   - Ручные правки в эти файлы запрещены: следующая регенерация их молча снесет, а гейт `tables_fresh` немедленно уронит сборку.
3. **Строгая кодировка UTF-8:**
   - Все файлы CSV и сгенерированные исходники C++ сохраняются строго в кодировке UTF-8 без BOM. В MSVC используется флаг `/utf-8` для корректной компиляции русских названий (`name_ru`, `desc_ru`).

## 2. СХЕМА КЛЮЧЕВЫХ ТАБЛИЦ ДАННЫХ

### 2.1. Таблица предметов (`data/items.csv`)
Генерирует: `src/game/item_table.h`, `src/game/item_table.cpp` через `tools/gen_item_table.py`.

| Колонка | Тип C++ | Назначение |
|:---|:---|:---|
| `id` | `ItemId` | Уникальный символьный идентификатор (`ak47`, `canned_meat`, `medkit`) |
| `name_ru` | `const char*` | Отображаемое имя на русском языке |
| `mass_g` | `uint32_t` | Масса в граммах (определяет физический вес и утомляемость) |
| `volume_cm3` | `uint32_t` | Объем в см³ (определяет вместимость в рюкзаках и карманах) |
| `slot` | `EquipSlot` | Слот экипировки (`MainHand`, `OffHand`, `Body`, `Head`, `Tool`) |
| `equip_kind` | `EquipKind` | Класс предмета (`WeaponRanged`, `WeaponMelee`, `Armor`, `Consumable`) |
| `durability` | `uint16_t` | Запас прочности предмета |
| `use_ms` | `uint32_t` | Время применения в миллисекундах (длина окна `Acting`) |
| `craft_station` | `StationKind` | Требуемый верстак для создания |
| `craft_tier` | `uint8_t` | Уровень технологии для крафта |

### 2.2. Таблица форм тел и суставов (`data/prop_forms.csv`)
Генерирует: `src/game/prop_form_table.h` через `tools/gen_prop_form_table.py`.

| Колонка | Тип C++ | Назначение |
|:---|:---|:---|
| `form_id` | `uint16_t` | Идентификатор формы тела (`human`, `mutant_dog`, `blob`) |
| `seg_index` | `uint8_t` | Порядковый индекс сегмента 0..6 |
| `role` | `FormRole` | Роль сегмента (`Pelvis`, `Torso`, `Head`, `ArmLeft`, `ArmRight`, `LegLeft`, `LegRight`) |
| `length` | `float` | Линейная длина сегмента в метрах |
| `radius` | `float` | Радиус коллизионной капсулы сегмента |
| `mass_kg` | `float` | Масса данного сегмента тела в килограммах |
| `parent_seg`| `int8_t` | Индекс родительского сегмента (-1 для корня Pelvis) |
| `jx, jy, jz`| `vec3` | Смещение шарнира сочленения в локальных координатах |

### 2.3. Таблица мобов и тварей (`data/mobs.csv`)
Генерирует: `src/game/mob_table.h`, `src/game/mob_table.cpp` через `tools/gen_mob_table.py`.
- Определяет здоровье `hp_max`, базовую скорость `walk_speed`, массу, размер AABB-капсулы, фракцию (`Citizen`, `Bandit`, `Mutant`, `Anomaly`), таблицу лута при гибели и параметры агрессивности.

### 2.4. Таблица материалов вокселей (`data/materials.csv`)
- Определяет физические свойства субвокселей: плотность, твердость для карвинга, цвет для реймаршера, шероховатость, эмиссионное свечение (неон) и скорость звука.

## 3. ЧЕТЫРЕ СТРОГИХ МАШИННЫХ ГЕЙТА ЦЕЛОСТНОСТИ ДАННЫХ

В CMake и ctest встроены 4 автоматических гейта, исключающих любую рассинхронизацию:

1. **`tables_fresh`:**
   - Запускает все генераторы `tools/gen_*.py` во временном буфере и сличает полученные файлы с закоммиченными в репозитории **побайтно**.
   - Если разработчик изменил `items.csv`, но забыл запустить `gen_item_table.py` — гейт падает с ошибкой.
2. **`csv_columns`:**
   - Проверяет использование каждого столбца в каждом CSV файле.
   - Столбец обязан иметь статус: `LIVE` (читается кодом), `GEN` (используется генератором), `WRITEONLY` (пишется в файл, но не читается) или `DEAD` (мёртв).
   - Появление нового столбца без вердикта немедленно окрашивает ctest в красный цвет.
3. **`row_law`:**
   - Проверяет равенство числа строк в CSV и статических констант размеров массивов в заголовках (`static_assert(kItemCount == N)`).
4. **`source_rules`:**
   - Сканирует все исходники на отсутствие запрещенных конструкций (`throw`, `dynamic_cast`, GLM/Eigen) и проверяет целостность байтов UTF-8 кириллических строк.

## 2. АНАТОМИЯ КАДРА И МАСШТАБА ТЕЛА

### 2.1 Кадр тела (`BodyFrame`)
Векторы кадра ортонормальны и ориентированы относительно гравитации этажа и направления взгляда (`Look`):
```cpp
struct BodyFrame {
    vec3 fwd;   // Взгляд, спроецированный на плоскость ходьбы (или tanA при вертикальном взгляде)
    vec3 left;  // Поперечная ось: left = normalize(cross(up, fwd))
    vec3 up;    // Против вектора гравитации слоя: up = -gravity.dir
};
```

### 2.2 Масштаб тела (`BodyScale`)
Привязан к полугабаритам силуэта `AABB` (`bodyHalf`):
- `H = 2.0f * dot(bodyHalf, up)` — полный рост вдоль вектора гравитации.
- `W = 2.0f * max(dot(bodyHalf, fwd), dot(bodyHalf, left))` — максимальный поперечник силуэта.

## 3. ОДОМЕТР ТЕЛА (`Gait`) И ДЕТЕРМИНИРОВАННЫЙ РАСЧЕТ ШАГА (ШАГ И3а)

### 3.1 Одометр как физическое состояние
Одометр хранит пройденный телом путь в метрах:
```cpp
struct Gait {
    float metres = 0.0f; // Накопленный путь в плоскости ходьбы
};
```
- **Единственный писатель:** `gait_step(reg, stack, layer, dt)` вызывается раз на сим-тик (125 Гц) строго после шага физики.
- **Инвариант опоры:** Путь накапливается **только** если тело стоит на тверди (`GravityAffected::grounded == true`). В свободном падении, полете или прыжке ноги не шагают:
  $$\Delta \text{metres} = \|\mathbf{v}_{\text{tangent}}\| \cdot \Delta t$$

### 3.2 Фаза и амплитуда походки (`GaitState`)
Для живого тела вычисляется нормализованное состояние походки:
- **Длина шага:** $S = k_{\text{StepStrideOfHeight}} \cdot H \approx 0.45 \cdot H$.
- **Полный цикл шага:** Два шага (левая и правая нога) = $2S$.
- **Фаза:** $\phi \in [0, 1)$:
  $$\text{cycles} = \frac{\text{metres}}{2S}, \quad \phi = \text{cycles} - \lfloor \text{cycles} \rfloor$$
- **Амплитуда:** $A = \min\left(1.0, \frac{\|\mathbf{v}_{\text{tangent}}\|}{v_{\text{walk}}}\right)$.

## 4. ДИНАМИЧЕСКИЙ ВЫВОД УГЛА РАЗМАХА НОГ (`gait_swing_max`)
Угол размаха ног $\theta_{\max}$ не подбирается художником «на глаз», а строго выводится из физико-геометрического треугольника стопы:
За один шаг стопа проходит от таза полшага вперёд и полшага назад:
$$\sin(\theta_{\max}) = \frac{\frac{1}{2} S}{L_{\text{leg}}} = \frac{0.5 \cdot k_{\text{StepStrideOfHeight}} \cdot H}{2.0 \cdot \text{sd.sz} \cdot H}$$
Для гуманоида из `prop_forms.csv`:
$$\theta_{\max} = \arcsin\left(\frac{0.5 \cdot 0.45}{0.76}\right) \approx 17.2^\circ \quad (0.30 \text{ rad})$$

## 5. ПРЯМАЯ КИНЕМАТИКА ДЕРЕВА СЕГМЕНТОВ (`form_gait_pose`)
Сегменты формы заданы иерархически в `prop_forms.csv`:
1. **Корень (`Torso`, parent = -1):**
   Позиционируется в `rootPos` с ориентацией кадра тела `qBody`.
2. **Дочерние сегменты (`Head`, `LeftArm`, `RightArm`, `LeftLeg`, `RightLeg`):**
   - Точка сустава в осях родителя: $\mathbf{j}_{\text{parent}}$.
   - Точка сустава в осях дочерней части: $\mathbf{j}_{\text{part}}$.
   - Колебание маятника по синусоиде:
     $$\text{swing} = A \cdot \theta_{\max} \cdot \sin(2\pi \phi)$$
   - Сторона определяется знаком поперечного смещения сустава $\text{sign}(jy)$:
     - **Нога:** $\alpha = \text{side} \cdot \text{swing}$
     - **Рука (противофаза):** $\alpha = -\text{side} \cdot \text{swing}$
   - Кватернион поворота вокруг оси «лево»:
     $$\mathbf{q}_{\text{local}} = \left[0, \sin\frac{\alpha}{2}, 0, \cos\frac{\alpha}{2}\right]$$
     $$\mathbf{q}_{\text{child}} = \text{normalize}(\mathbf{q}_{\text{parent}} \cdot \mathbf{q}_{\text{local}})$$
   - Мировое положение через замыкание сустава:
     $$\mathbf{pos}_{\text{child}} = \mathbf{pos}_{\text{parent}} + \mathbf{R}_{\text{parent}}(\mathbf{j}_{\text{parent}}) - \mathbf{R}_{\text{child}}(\mathbf{j}_{\text{part}})$$

## 6. ЗВУК ШАГОВ ИЗ ОДОМЕТРА (ШАГ И3б)
- **Проблема старого кода:** Ритм шагов в `encumbrance_step` тикал по независимому таймеру `footstep_period_ticks`, расходясь с реальным смещением ног визуальной походки.
- **Новый канон (И3б):** Звук шага триггерится строго в момент касания стопы пола:
  $$\sin(2\pi \phi) \text{ пересекает } 0$$
  - Левая нога касается земли при $\phi = 0.0$ (переход через ноль).
  - Правая нога касается земли при $\phi = 0.5$ (переход через полупериод).
- **Детектор перехода:**
  Сравнение `floor(2 * cycles_prev) != floor(2 * cycles_curr)` гарантирует ровно один звуковой импульс на каждый физический шаг без пропуска тиков и без повторов при остановке.

## 7. ПОЗЫ ДЕЯНИЙ ПО ОКНУ ACTING (ШАГ И3в)
- Нормализованная фаза текущего действия $E \in [0, 1000]$ вычисляется функцией:
  ```cpp
  inline std::uint16_t acting_phase_e3(const Acting& a, ActSlot s, std::uint64_t tick);
  ```
- **Модуляция позы по действию:**
  - Если слот `ActSlot::Main` занят глаголом (удар, выстрел, замах, перевязка), фаза окна $E / 1000.0$ интерполирует углы суставов рук между позой походки и ключевым положением глагола (`VerbPoseTable`).
  - При срыве действия через единую дверь `break_acting` поза мгновенно возвращается к дефолтной кинематике походки.

## 8. ИНВАРИАНТ РАСЧЛЕНЕНИЯ И СФЕР ГОЛОВЫ (CANON S28, S1)
- **Тороидальное обертывание голов и суставов:**
  - При рендере сфер `FormPrim::Sphere` (например, головы манекена или сферических шарниров) радиус вычисляется строго как $r = \text{sx} \cdot H$.
  - Координаты сфер при переходе через границу 128³ тора обертываются через `wrapf(pos, kWorldExtent)`, исключая артефакты растягивания и вывернутых нормалей.
- **Расчленение (Dismemberment):**
  - При разрушении сустава дочерняя ветвь дерева формы отсекается: флаг присутствия сегмента сбрасывается в маске живого тела, а отсеченный сегмент порождает независимый твердый объект с начальной скоростью родительского тела.

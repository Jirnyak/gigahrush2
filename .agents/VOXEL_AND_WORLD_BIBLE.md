## 1. МАТЕМАТИКА 3D ТОРА 128³ (TOROIDAL TOPOLOGY)

1. **Топологический инвариант мира:**
   - Мир GigaHrush 2 — это трехмерный тор $T^3 = S^1 \times S^1 \times S^1$ с периодом $L = 256.0$ метров по осям X, Y и Z.
   - Мир состоит из $128 \times 128 \times 128 = 2\,097\,152$ макроклеток.
   - Размер одной макроклетки $kCellSize = 2.0$ метра ($kWorldExtent = 128 \times 2.0 = 256.0$ м).
   - В пространстве нет физических «краёв» или «стен мира». Падение или полет в любом направлении приводит к бесшовному возвращению с противоположной стороны тора.

2. **Тороидальная арифметика координат (`src/core/wrap.h`):**
   ```cpp
   // Заворачивание макро-индекса клетки [0, 127]
   inline int wrapi(int x, int extent = kGridDim) {
       int m = x % extent;
       return m < 0 ? m + extent : m;
   }

   // Заворачивание мировой вещественной координаты [0.0, 256.0)
   inline float wrap_macro(float v, float extent = kWorldExtent) {
       float m = std::fmod(v, extent);
       return m < 0.0f ? m + extent : m;
   }

   // Кратчайший тороидальный вектор смещения в диапазоне [-extent/2, extent/2]
   inline float wrap_delta(float a, float b, float extent = kWorldExtent) {
       float d = a - b;
       float half = extent * 0.5f;
       if (d > half)  d -= extent;
       if (d < -half) d += extent;
       return d;
   }
   inline vec3 wrap_delta(const vec3& a, const vec3& b, float extent = kWorldExtent) {
       return vec3{
           wrap_delta(a.x, b.x, extent),
           wrap_delta(a.y, b.y, extent),
           wrap_delta(a.z, b.z, extent)
       };
   }
   ```
   **Железный закон расстояний:** Любое измерение дистанции между сущностями, трассировка лучей, расчет гравитации и распространение звука ОБЯЗАНЫ использовать `wrap_delta`. Обычное евклидово вычитание $(a - b)$ за пределами полупериода 128 м является критическим дефектом.

## 2. СУБВОКСЕЛЬНЫЕ АТОМЫ 0.25 М И БИТОВЫЕ МАСКИ (`SubMask`)

1. **Разрешение и масштаб субвокселей:**
   - Каждая макроклетка ($2.0 \times 2.0 \times 2.0$ м) делится на $8 \times 8 \times 8 = 512$ субвокселей.
   - Линейный размер субвокселя: $0.25$ метра ($25$ сантиметров).
   - Субвоксель — это неделимый квант геометрии мира. Именно субвоксели определяют коллизии пуль, точки соприкосновения ног при ходьбе, сколы от пуль и проломы от кувалды.

2. **Битовое представление (`src/world/submask.h`):**
   - 512 субвокселей упакованы ровно в 512 бит = 8 слов по 64 бита (`uint64_t words[8]`).
   - Индексация субвокселя внутри клетки $(sx, sy, sz) \in [0, 7]^3$:
     $$\text{bit\_index} = sx + sy \cdot 8 + sz \cdot 64$$
     $$\text{word\_index} = \text{bit\_index} \gg 6 \quad (0..7), \quad \text{bit\_offset} = \text{bit\_index} \& 63$$
   - Быстрый тест наличия субвокселя:
     ```cpp
     inline bool test(int sx, int sy, int sz) const {
         int idx = sx + (sy << 3) + (sz << 6);
         return (words[idx >> 6] & (1ULL << (idx & 63))) != 0;
     }
     ```
   - Заполнение и очистка выполняются мгновенно через битовые маски. Проверка клетки на абсолютную монолитность (`is_solid()`) или полную пустоту (`is_empty()`) занимает ровно 8 сравнений слов без циклов перебора.

3. **Связь субмаски и материалов вокселей:**
   - Вектор материалов `data/materials.csv` задает плотность, вязкость, упругость, цвет и проводимость звука.
   - Воздух — это `MaterialId = 0`.
   - Если все 512 бит субмаски сброшены в `0`, макроклетка автоматически помечается как `CellType::Air`.
   - Если маска частично заполнена — клетка считается составной (`CellType::Carved`), а физический движок проверяет субмаску побитовым `AND` с AABB капсулы тела.

## 3. ИЗОТРОПИЯ И 8 РЕЖИМОВ ГРАВИТАЦИИ (`src/world/gravity.h`)

1. **Закон изотропии пространства (All 3 Axes Equal):**
   - Пространство тора изотропно. Ось Z не является избранной.
   - Вектор гравитации задаётся режимом этажа или локальной зоны через перечисление `GravityRegime`:
     - `NegZ` (стандартный пол на -Z, вектор $\{0, 0, -1\}$)
     - `PosZ` (потолочная гравитация на +Z, вектор $\{0, 0, 1\}$)
     - `NegX`, `PosX` (боковая гравитация вдоль оси X)
     - `NegY`, `PosY` (боковая гравитация вдоль оси Y)
     - Диагональные режимы (переходные гравитационные линзы)
2. **Преобразование векторов фрейма:**
   ```cpp
   inline vec3 regime_down(GravityRegime r);
   inline vec3 regime_up(GravityRegime r) { return -regime_down(r); }
   inline vec3 regime_forward(GravityRegime r, float yaw);
   ```
   **Запрет жестких направлений:** Любой расчет падения тел, поиска пола под ногами (`floor_standable`), растекания жидкости в клеточном автомате и провисания проводов обязан использовать `regime_down(regime)`.

## 4. ДИНАМИЧЕСКИЙ КАРВИНГ И РАЗРУШЕНИЕ (`src/world/destruct.h`)

1. **Механика карвинга (Sub-voxel Carving):**
   - Удар кувалды, попадание разрывной пули или взрыв гранаты вызывают выемку сферы или конуса субвокселей:
     `carve_sphere(world, center, radius, MaterialId::Air);`
   - Карвинг атомарно сбрасывает биты субмасок в затронутых клетках, порождает облако физических обломков и частицы пыли в `VerletPass`, и инвалидирует фоновый кэш навигации этажа.
2. **Якорение объектов (Sub-Voxel Anchoring):**
   - Все настенные терминалы, лампы, щитки, розетки и трубы прикреплены к субвоксельным граням через компонент `SubVoxelAnchor`.
   - При выемке субвокселей, служивших физической опорой якоря:
     - Опора исчезает $\to$ объект автоматически отрывается от стены.
     - Тяжелый объект переходит в режим падения `SimpleFall` или `RagdollRoll`.
     - Лампочка раскалывается с переходом в `GpuHandoff` (всплеск осколков).
     - Провод под действием верле-симуляции обрывается и начинает свободно хлестать по воздуху.

## 5. УНИВЕРСАЛЬНЫЙ ПРИМИТИВ ПОВЕРХНОСТЕЙ (`src/world/surface.h`)

1. **Запрос поверхностей `surface_face_at`:**
   - Движок предоставляет единый атомарный интерфейс для поиска пригодных граней вокселей:
     ```cpp
     struct SurfaceFace {
         vec3 pos;          // Мировая позиция центра субграни
         vec3 normal;       // Нормаль наружу (-1..+1 по одной из осей)
         int faceDir;       // Индекс грани 0..5 (NegX, PosX, NegY, PosY, NegZ, PosZ)
         MaterialId mat;    // Материал основания
     };
     bool surface_face_at(const World& world, ivec3 cell, int faceDir, SurfaceFace& outFace);
     ```
2. **Глаголы постановки контента (CANON S23):**
   - Генераторы модулей этажей (`khrushi`, `padic`, `blame`) никогда не содержат захардкоженных циклов перебора координат.
   - Расстановка мебели, настенных устройств, выключателей и ламп выполняется тремя декларативными глаголами постановки:
     - `place_wall_devices(...)` — расстановка на вертикальные субграни;
     - `place_floor_fixtures(...)` — расстановка на горизонтальные субграни пола;
     - `place_ceiling_lights(...)` — расстановка потолочных светильников.

## 3. Настоящий блокер — не размер, а `static` внутри цикла

Разрез блокируют не строки, а **функциональные статики, живущие на пятом уровне
вложенности внутри `main()`**. Их три кластера, и они принципиально разные.

Переезжает вместе со своим окном. Ничего не нужно продумывать.

сначала поднять их в структуру-владельца, иначе разрез либо продублирует
состояние, либо потеряет его между кадрами.

### 4.1. Почему №1 первым, а не самое большое

Регион 293–763 — 470 строк, **уже** свободные функции, **уже** с явными
параметрами, **нулевое** сцепление. Это извлечение — механический перенос текста
и правка инклюдов. Оно доказывает, что разрез работает, ничего не ломая, и даёт
шаблон для остальных семи.

Начинать с 1802-строчного блока симуляции — значит начинать с единственного
места, где нужна новая структура состояния, ещё не имея опыта разреза на этом
файле. Это тот же принцип, по которому [спека 02](02_VOXEL_PHYSICS_AND_FLUIDS.md)
ставит газ первым полем, а не воду.

## 5. Проектируемые структуры

### 5.1. `FrameIntents` — разблокирует №7

```cpp
// src/app/frame_intents.h — НОВЫЙ.
// ~20 булей, которые сегодня живут отдельными локальными переменными в main()
// и пишутся плоской таблицей if (has(X)) на строках 2600-2730.
//
// ПОЧЕМУ POD-СТРУКТУРА, А НЕ БИТМАСКА: каждое поле читается по имени в
// разных местах кадра. Битмаска сэкономила бы 20 байт и стоила бы
// читаемости в двадцати местах — не та сделка. AGENTS.md требует POD,
// а не упаковки ради упаковки.
struct FrameIntents {
    bool saveWanted = false;
    bool loadWanted = false;
    bool rideWanted = false;
    bool navRebakeWanted = false;
    // ... остальные ~16, по одному на ConsoleRequest
};
static_assert(std::is_trivially_copyable_v<FrameIntents>);
```

### 5.2. `AppState` — разблокирует симуляцию и рендер

```cpp
// src/app/app_state.h — НОВЫЙ. Владелец всего, что сегодня живёт
// функциональными статиками кластера C.
//
// ЭТО НЕ БОГ-ОБЪЕКТ И НЕ КЛАСС. Это POD-агрегат владения: ни одного метода,
// ни одного виртуального вызова, ни одной инварианты внутри. Логика остаётся
// в свободных функциях, которые принимают AppState& — ровно то, что
// AGENTS.md называет data-oriented.
struct AppState {
    // Кластер C, поднятый из вложенности. Порядок — по подсистеме,
    // не по строке, где статик оказался исторически.
    struct {
        std::vector<std::uint32_t> alive, pins;
        FallClock fall;
    } wires, cloths;

    std::vector<BodyPush> pushBodies;
    RpgCombatSheet rpgcmbtSheet;

    // Латчи env, сегодня читаемые getenv КАЖДЫЙ КАДР на строках
    // 5613, 5646, 5668 — см. спеку 04 §8. Здесь они читаются один раз.
    bool noGpuCull = false, wireNoSim = false;
    bool particleNoSim = false, antourageDebug = false;

    // Латчи логов: сегодня 4 отдельных статика тика.
    std::uint64_t lastCorpseLootLogTick = 0;
    std::uint64_t corpAtkLog = 0, wallLog = 0, magLastRideLog = 0;
};
```

**Побочная выгода, не главная цель:** подъём `noGpuCull`/`wireNoSim`/
`particleNoSim` в `AppState` закрывает нескэшированные `std::getenv` каждый кадр
из [спеки 04](04_RENDER_AND_ACOUSTICS.md) §8. Одна правка, два дефекта.

## 7. Критерии приёмки

### 7.1. Гейт на рост — иначе долг вернётся

§29 записан против 5616, сегодня 5927. **Без гейта следующая подсистема добавит
своё.**

- [ ] `check_source_rules.cmake` получает правило: `src/app/main.cpp` не длиннее
      **N строк**, где N — текущее значение минус то, что вынесено. Ratchet:
      число только уменьшается.
- [ ] Правило пинует **точное** число, а не диапазон. Слабый пин — это дефект,
      который [спека 05](05_TESTING_AND_PERF_BUDGETS.md) §2.1 уже нашла на
      `files_scanned`.

### 7.2. Каждое извлечение — отдельный коммит

- [ ] Один регион = один коммит. Восемь коммитов, не один.
- [ ] После каждого: `tools\win\build.bat` зелёный, `ctest` 4/4, `source_rules`
      PASS. **Ноль предупреждений** при `/W4 /wd4100`.
- [ ] Ни одного изменения поведения ни в одном из восьми. Извлечение — перенос
      текста, а не рефакторинг логики. Смешивать их — способ получить регрессию,
      которую невозможно локализовать.

### 7.3. Проверка, что разрез настоящий

- [ ] После №1–6: `main()` короче 4451 строки на сумму вынесенного, и это
      печатается в коммите числом.
- [ ] Ни один вынесенный файл не включает `SDL`/`Vulkan`, если он не рендерный —
      `giga_core`/`giga_game` уже гейтятся на это в `source_rules`.
- [ ] Два дубля инклюдов убраны.

### 7.4. Кластер C

- [ ] Ни одного `static` внутри тела `main()` после подъёма в `AppState`.
      Гейт: `rg -n '^\s+static ' src/app/main.cpp` пуст (кроме констант
      файлового уровня).
- [ ] `FallClock` проводов и ткани живут в `AppState`, а не в блоке рендера.
      Это состояние симуляции; его место — в симуляции.

## 9. Явные не-цели

- **Не превращать `AppState` в класс с методами.** POD-агрегат владения, логика
  в свободных функциях. Иначе это монолит с другим именем, а `AGENTS.md` его
  запрещает не за размер, а за форму.
- **Не резать 2731–4532 раньше Ф8.** 1802 строки, читающие сотни локальных
  переменных, без структуры-владельца дадут либо дублирование состояния, либо
  его потерю между кадрами.
- **Не смешивать извлечение с исправлением.** Восемь коммитов переноса, потом
  правки. Регрессия в смешанном коммите не локализуется.
- **Не создавать `app/utils.cpp`.** Свалка без темы — это тот же монолит,
  разрезанный по алфавиту.

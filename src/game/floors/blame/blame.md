# Blame — мегаструктурная пустота (этаж 5). Анкета модуля

Технодемо движка: этаж, чья работа — показать, зачем честный изотропный тор
256×256×256 м, а не широкий плоский блин. Узкий коридор обрывается в пропасть
глубиной во весь мир (z враппится — падение бесконечно), каньоны замкнуты в
кольца без швов, стены циклопические, переходы — решётчатые мосты и консольные
серпантины. Построен 2026-08-17, в тот же день ретюн по живому плейтесту
владельца. Замысел и решения — владельца; см. также memory
`blame-floor-module` и problems.md §57.

## Файлы

- `blame.h` — манифест: клейм номера **5** (паттерн дал бы Commercial),
  `kBlameGravity = NegZ`, `kBlameGroundCoord = 3` — НАМЕРЕННО равен
  падиковскому, чтобы не трогать `save.h kArrivalCoord` и глобальные
  frame-хелперы `floor_gen.h` (шов «второй модуль → per-kind хелперы» отложен
  сознательно).
- `blame_gen.cpp` — вся геометрия (разбор ниже).
- `blame_module.cpp` — регистрация клейма. Пропсов/лута/НПЦ у модуля ещё нет.

Швы наружу: строка в `floor_spec.h/.cpp` (FloorKind::Blame, спека: pop 24,
hostility 0.8), строка ролей в `role.h`, room-mix + три диспетч-строки +
доруэи в `floor_gen.cpp` (blame отдаёт **0 дверей** — проёмы без косяков),
клейм в `floor_catalog.cpp`. Тестовые пины: suite_floorcatalog (клейм бьёт
паттерн), suite_navcache 540 = 15×**6**×6.

## Пайплайн генератора (порядок = скульптура, менять осторожно)

Всё — чистая функция (seed, number). Транзиентное поле `Sculpt` 128³ CellType
(2 МБ), стадии работают по нему, потом один общий штамп в грид + суб-воксельная
грамматика поверх. Отдельный rng-хэш на семейство стадий (carve/town/maze/
face/deck) — стадию можно тюнить, не перекатывая остальные.

1. `build_plan` — скаляры: `rot` (поворот всего массинга по тору — от него
   зависит, какие узлы решётки в массе, какие в пустоте), стены A/B
   (tA 22–28 / tB 18–24), **пропасть gap 9–12** (сужена с 14–20 по ретюну),
   **щель slit 3–4**, платформа zPlat 18–24, **стена C** (tC 12–16, режет
   тыловой каньон надвое), ребро yc1/tc1 (вся высота), небесная плита
   yc2/tc2/zc2 (z ≥ 56–80), колодец в стене A, уровни мостов deckZ[8]
   (7 сеяных + zPlat−6 для мостков через щель).
2. `sculpt_masses` — кольца стен, ребро, плита, платформа (верхний слой
   kMatSlabTan = улица), стена C ПОСЛЕДНЕЙ (её бетон побеждает улицу в своём
   пятне — город упирается в стену).
3. `carve_voids` / `carve_bores` / `sculpt_pipes` — пропасть (вся высота, вся
   y — режет ребро и плиту, их срезы потом ловят мосты), щель, террасы кромки
   платформы (3 ступени по 2), колодец, штреки 3×3 сквозь стены, две трубы
   kMatPipeMetal с лазом 1×1 и ходьбой поверху.
4. `sculpt_town` — домики на джиттер-сетке 9: полые коробки 4–6², стены
   kMatSlabTan высотой 2–4, дверь 1×2, «влезает» = улица снизу + небо сверху
   (поэтому под ребром/стеной C домов нет; ±4 клетки от граней C — запрет,
   там серпантины).
5. `carve_labyrinth` — друнканые коридоры 2×2 в толще ВСЕХ ТРЁХ стен, банды
   z = 3+6k; выход на грань: 1/3 пробивает обшивку насквозь (обрыв в бездну),
   2/3 тупик.
6. `sculpt_lattice` — решётка 4×4: колонна >50% пуста → пилон 7×7 на всю
   высоту; лобби-банды z = 8k+3..8k+4 с ПРИНУДИТЕЛЬНЫМ полом на 8k+2 (прибытие
   z=3 всегда стоит); дверные проёмы пилонов на чётных k по ±x; ствол 3×3
   режется ПОСЛЕДНИМ.
7. `stamp_sculpt` → грид; дальше суб-воксельная грамматика:
   - `stamp_bridges` — ЧИСТЫЙ СКАН solid|air|solid по строкам на каждом deckZ
     (план-координаты x: план-0 внутри стены A, поэтому ран не пересекает
     шов); пролёт 3–44 клеток, настил kGrateBars/kMatTread в словах 7 клетки
     z−1, ~1/4 длинных сломаны (щель 1 клетка + зубья kMatRubble).
   - `stamp_catwalks` — от пилонов по ±x на чётных бандах до первой ответившей
     грани (1-рядные).
   - `stamp_serpentine` — консольный серпантин: **ДВЕ ДОРОЖКИ** по чётности
     лега (спуск и возврат в разных клетках глубины — как ряды A/B у падика)
     + площадки 2×2 на обе; лег = 24 ступени 2/8, минус 3 клетки; zTop
     подгоняется до кратности 3. Ретюн-фикс: в один-дорожечной версии
     встречные марши пересекались в середине пролёта.
   - `stamp_cornice` — карнизы 1 клетка глубиной.
   - `stamp_roofs` — крыши домов в СЛОВАХ 6–7 КЛЕТКИ НИЖЕ (конвенция
     падиковского сэндвича). Ретюн-фикс: нижне-словная крыша = клетка-капкан,
     см. problems.md §57.
   - `stamp_lattice_markers` — hub-pad перекраска, угловые столбы, финальная
     зачистка стволов.

`blame_declare_rules` = регистр суб-материалов + гравитация NegZ;
`blame_apply_rules` = обнуление флюид-полей (рециклlevel слот).
